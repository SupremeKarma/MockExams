# MockExams Platform - Comprehensive Overview

## 🚀 Platform Vision

MockExams is an AI-powered comprehensive exam preparation platform designed for students at Purbanchal University's BIT program and beyond. It combines 8 advanced AI systems to create a personalized, adaptive learning experience that maximizes exam success.

---

## 🤖 8 AI-Powered Systems

### 1. **AI Socratic Tutor** (`/tutor`)
- **Purpose**: Interactive tutoring through guided questioning
- **Features**:
  - Socratic method: guides students to discover answers themselves
  - Sample questions organized by subject and difficulty
  - Real-time chat interface with typing indicators
  - Code snippet support with copy functionality
  - Subject filtering (Programming, Data Structures, Mathematics, Database, Microcontroller)
- **How it helps**: Transforms passive learning into active discovery

### 2. **Adaptive Exam Engine** (`/exams`)
- **Purpose**: AI-powered mock exams that adjust difficulty in real-time
- **Features**:
  - Real-time difficulty adjustment based on performance
  - Multiple exam categories (Science, Mathematics, Engineering, Medical, Competitive)
  - Instant feedback and score analysis
  - Exam listing with duration and question count
  - Clickable exam cards for seamless navigation
  - Progress tracking across all attempts
- **How it helps**: Provides practice that matches your current skill level

### 3. **FSRS v6 Flashcards** (`/flashcards`)
- **Purpose**: Scientific spaced repetition for long-term retention
- **Features**:
  - Optimized based on Forgetting Curve theory
  - 3D card flip animation
  - Next review scheduling based on recall strength
  - Semester-based organization (1-8)
  - Subject filtering
  - Fullscreen mode for focused study
  - FSRS v6 rating system (1-4 scale)
  - 98% retention rate target
- **How it helps**: Maximizes retention with proven scientific spacing

### 4. **Weak Area Detection** (`/analytics`)
- **Purpose**: AI identifies struggling topics and recommends intervention
- **Features**:
  - Subject-level mastery tracking
  - Weak topic identification with priority levels
  - Performance comparison with university toppers
  - Speed optimization metrics
  - Topic-specific intervention recommendations
  - Targets for each subject (e.g., "85% Goal")
- **How it helps**: Concentrates effort on what needs improvement most

### 5. **Personalized Study Planner** (`/study-plan`)
- **Purpose**: AI generates optimized weekly study schedules
- **Features**:
  - Personalized weekly calendar (Monday-Saturday)
  - Session types: Lecture, Practice, Flashcards, Projects
  - Time allocation based on weak areas
  - Daily/Weekly view toggle
  - AI recommendations for study optimization
  - Download and share functionality
  - Weak area highlighting with targeted action plans
- **How it helps**: Removes guesswork from study planning

### 6. **Performance Analytics Dashboard** (`/dashboard`)
- **Purpose**: Real-time overview of learning progress
- **Features**:
  - Overall rank and percentile
  - Accuracy matrix visualization
  - Total study time tracking
  - Current streak with milestone targets
  - Subject-wise proficiency breakdown
  - Recent assessment history with retake buttons
  - AI systems showcase
  - Engagement statistics
- **How it helps**: Provides clarity on progress and identifies next steps

### 7. **Competitive Leaderboard** (`/leaderboard`)
- **Purpose**: Global rankings and gamification
- **Features**:
  - Global rankings
  - Top 3 podium display
  - Personal ranking card
  - Badges and achievements (Top 10%, Streak, Speedster)
  - Monthly honor roll
  - Exam-specific filtering
  - Search functionality
  - Quick tips for ranking improvement
- **How it helps**: Adds motivation through healthy competition

### 8. **Study Materials Hub** (`/notes`)
- **Purpose**: Curated high-frequency exam topics and resources
- **Features**:
  - Semester-based organization (1-8)
  - Subject filtering
  - Code topics with verified algorithms
  - Theory FAQs with university exam guidance
  - Key points highlighted
  - Code snippet copy functionality
  - Priority importance levels
  - Search across topics
  - Mathematical formulations
- **How it helps**: Centralizes essential study materials

## 🎨 Design System Enhancements

### Color Palette
- **Primary**: Indigo (#4f46e5) - Main brand color
- **Secondary**: Cyan (#0891b2) - Supporting color
- **Accent**: Amber (#d97706) - Call-to-action elements
- **Success**: Emerald (#059669) - Positive states
- **Danger**: Rose (#dc2626) - Alerts/warnings

### Typography
- **Font Stack**: Inter/Geist Sans + JetBrains Mono
- **Hierarchy**: Bold font weights for headlines, medium for body
- **Responsive**: Text scales proportionally on mobile/tablet/desktop

### Shadows & Depth
- **Base Shadow**: `0 4px 20px rgba(0, 0, 0, 0.03)`
- **Hover Shadow**: `0 8px 30px rgba(0, 0, 0, 0.06)`
- **Button Shadow**: `0 4px 12px rgba(79, 70, 229, 0.25)`

### Gradients
- **Primary Gradient**: Indigo → Purple → Blue
- **Success Gradient**: Emerald → Teal
- **Warm Gradient**: Amber → Red
- **Cool Gradient**: Cyan → Teal

### Animations
- **Float**: Subtle Y-axis movement (4s ease-in-out)
- **Pulse Glow**: Opacity shimmer (3s ease-in-out)
- **Slide In**: 0.5s directional slide with easing
- **Fade Scale**: Opacity + scale combination
- **Gradient Shift**: Background position animation (8s)

### Responsive Design
- **Mobile**: 375px viewport with touch-optimized interactions
- **Tablet**: 768px viewport with adjusted spacing
- **Desktop**: 1280px viewport with expanded layouts
- **Accessibility**: Reduced motion support via prefers-reduced-motion

## 📊 Technical Architecture

### Frontend Stack
- **Framework**: Next.js 13+ (App Router)
- **Styling**: Tailwind CSS + Custom CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **State Management**: React Hooks + Context API
- **Real-time**: Firebase Firestore listeners

### Backend Stack
- **Authentication**: Firebase Auth
- **Database**: Firestore
- **Hosting**: Firebase Hosting
- **Functions**: Cloud Functions (for API endpoints)

### Database Schema
```
collections:
├── exams
│   ├── id
│   ├── title
│   ├── category
│   ├── duration_minutes
│   ├── questions_count
│   ├── is_published
│   ├── visibility
│   └── created_at
├── exam_attempts
│   ├── user_id
│   ├── exam_id
│   ├── score
│   ├── total_marks
│   ├── attempted_at
│   └── time_spent_seconds
└── users
    ├── uid
    ├── displayName
    ├── email
    ├── study_streak
    └── total_points
```

## 🛠️ Development Guidelines

### Component Organization
- Reusable components in `/components`
- Page-specific components inline
- Shared utilities in `/lib`
- Data files in `/data`

### Naming Conventions
- Components: PascalCase (`ExamCard.tsx`)
- Utilities: camelCase (`formatDate.ts`)
- Constants: UPPER_SNAKE_CASE
- CSS classes: kebab-case

- TypeScript for type safety
- Consistent formatting
- Accessibility compliance (WCAG AA)
