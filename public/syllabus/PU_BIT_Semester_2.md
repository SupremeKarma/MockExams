## Detailed Course Outlines

### Mathematics-II (BIT151HS)
**Credits**: 3 | **Type**: Core

Multiple integrals, differential equations, Fourier series, and functions of a complex variable.

#### Key Syllabus Units:
1. **Multiple Integrals**
2. **Differential Equations of the First Order**
3. **Linear Differential Equations**
4. **Fourier Series and Integrals**
5. **Functions of a Complex Variable**
6. **Complex Series, Residues and Poles**

---

### Digital Logic (BIT152CO)
**Credits**: 3 | **Type**: Core

Number systems, Boolean algebra, combinational and sequential circuit design, registers and counters.

#### Key Syllabus Units:
1. **Number Systems**
2. **Boolean Algebra and Logic Gates**
3. **Simplification of Boolean Functions**
4. **Combinational Logic**
5. **Sequential Logic**
6. **Registers and Counters**

---

### Discrete Structure (BIT153HS)
**Credits**: 3 | **Type**: Core

Set theory, counting, logic, relations, graphs and trees, order relations, and automata theory.

#### Key Syllabus Units:
1. **Set Theory and Matrices**
2. **Function and Counting**
3. **Logic**
4. **Relation and Digraphs**
5. **Graph and Tree**
6. **Order Relation and Structure**
7. **Automata, Language and Grammar**

---

### Object-Oriented Programming in C++ (BIT154CO)
**Credits**: 3 | **Type**: Core

C++ OOP fundamentals — classes, constructors, operator overloading, inheritance, polymorphism, templates, and file handling.

#### Key Syllabus Units:
1. **Introduction to Object Oriented Programming**
2. **C++ Programming Concept**
3. **Functions Used in C++**
4. **Classes and Objects**
5. **Constructor & Destructor**
6. **Operator Overloading**
7. **Inheritance**
8. **Virtual Functions and Polymorphism**
9. **File Handling**
10. **Templates and Namespaces**
11. **Exception Handling**

---

### Financial Management and Accounting (BIT155MS)
**Credits**: 3 | **Type**: Core

Financial management fundamentals, capital budgeting and structure, and core accounting processes and statements.

#### Key Syllabus Units:
1. **Nature of Financial Management**
2. **Time Value of Money**
3. **Capital Budgeting**
4. **Working Capital**
5. **Capital Structure**
6. **Dividends**
7. **Nature of Accounting**
8. **Accounting Process**
9. **Financial Statement**
10. **Financial Analysis**
11. **Cash Flow Statement - Direct Method**

---

### Project-II (BIT156CO)
**Credits**: 2 | **Type**: Project / Practical

Group software project (2-3 students) built using Object-Oriented Programming in C++ — 45 lab hours.

#### Key Syllabus Units:
1. **Topic Selection & Information Gathering**
2. **System Requirements & Specifications**
3. **Coding & Implementation**
4. **Documentation & Final Presentation**
