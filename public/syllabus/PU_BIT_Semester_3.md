## Detailed Course Outlines

### Numerical Methods (BIT201HS)
**Credits**: 3 | **Type**: Core

Numerical solutions to nonlinear equations, interpolation, linear systems, differentiation/integration, and ODEs.

#### Key Syllabus Units:
1. **Errors in Numerical Computation**
2. **Solution of Nonlinear Equations (Bisection, Newton-Raphson)**
3. **Interpolation & Least Square Methods**
4. **System of Linear Equations (Direct & Indirect Methods)**
5. **Numerical Differentiation & Integration**
6. **Numerical Solution of ODEs (Euler, Runge-Kutta)**

---

### Microcontroller (BIT202CO)
**Credits**: 3 | **Type**: Core

8051 microcontroller architecture, instruction set, I/O and timer programming, interrupts, and peripheral interfacing.

#### Key Syllabus Units:
1. **Introduction to Microcontroller & 8051 Architecture**
2. **Instruction Set & Addressing Modes**
3. **Stack, I/O Port Interfacing & Programming**
4. **Timers and Serial Port**
5. **Interrupts and Interfacing Applications**

---

### Data Structure and Algorithm (BIT203CO)
**Credits**: 3 | **Type**: Core

Core data structures — stacks, queues, lists, trees, graphs — plus sorting, searching, and algorithm efficiency.

#### Key Syllabus Units:
1. **Introduction & Algorithm Efficiency**
2. **Stack & Queue**
3. **List and Linked List**
4. **Recursion**
5. **Trees (BST, AVL, Huffman)**
6. **Sorting (Quick, Merge, Heap)**
7. **Searching, Hashing & Graphs (DFS, BFS, Dijkstra)**

---

### Computer Network and Data Communication (BIT204CO)
**Credits**: 3 | **Type**: Core

Networking fundamentals, the OSI/TCP-IP layered model, data link/network/transport layers, and network security.

#### Key Syllabus Units:
1. **Introduction to Networking & Data Communication**
2. **Layered Network Architecture (OSI, TCP/IP)**
3. **Data Transmission & Physical Layer**
4. **Data Link Control (Error Detection, HDLC)**
5. **Network Layer (IP Addressing, Subnetting, Routing)**
6. **Transport & Application Layer**
7. **Network Security (Cryptography, SSL/TLS, Firewall)**

---

### System Analysis and Design (BIT205CO)
**Credits**: 3 | **Type**: Core

SDLC models, process/conceptual modeling with DFDs and ERDs, systems analysis and design, and object-oriented analysis with UML.

#### Key Syllabus Units:
1. **Overview of Systems Analysis & Design (SDLC Models)**
2. **Process & Conceptual Modeling (DFD, ERD)**
3. **Logic Modeling (Decision Table/Tree)**
4. **Systems Analysis (Requirements, Feasibility)**
5. **Systems Design & Implementation**
6. **Object-Oriented Analysis & Design (UML)**

---

### Project-III (BIT206CO)
**Credits**: 2 | **Type**: Project / Practical

Group project (2-3 students) developing a microcontroller (BIT202CO)-based system — 45 lab hours.

#### Key Syllabus Units:
1. **Title Identification & Proposal Writing**
2. **Mid-Term Presentation**
3. **Pre-Final Submission & Final Presentation**
