## Detailed Course Outlines

### Probability and Statistics (BIT251HS)
**Credits**: 3 | **Type**: Core

Descriptive statistics, probability theory, theoretical distributions, estimation, hypothesis testing, and correlation/regression.

#### Key Syllabus Units:
1. **Nature and scope of statistics**
2. **Data and its collection**
3. **Classification and tabulation of data**
4. **Diagrammatic and graphic presentation**
5. **Measures of central tendency**
6. **Measures of dispersion**
7. **Probability**
8. **Theoretical distribution (Binomial, Poisson, Normal, Hyper-geometric)**
9. **Estimation theory and testing of hypothesis**
10. **Chi-Square distribution**
11. **Correlation and regression analysis**

---

### Computer Organization and Architecture (BIT252CO)
**Credits**: 3 | **Type**: Core

Computer instruction sets, control unit design, CPU architecture, pipelining, memory organization, and multiprocessors.

#### Key Syllabus Units:
1. **Introduction**
2. **Computer organization and design**
3. **Control unit design**
4. **Central processing unit**
5. **Pipeline and vector processing**
6. **Computer arithmetic**
7. **Input and output organization**
8. **Memory organization**
9. **Multiprocessor**

---

### Operating System (BIT253CO)
**Credits**: 3 | **Type**: Core

Process/thread management, memory management, file systems, I/O, deadlocks, and distributed systems.

#### Key Syllabus Units:
1. **Introduction**
2. **Processes and Threads**
3. **Memory Management**
4. **File Systems**
5. **Input/Output**
6. **Deadlocks**
7. **Real Time System**
8. **Distributed System**
9. **Case study (UNIX/LINUX/Windows/Android/iOS)**

---

### Database Management System (BIT254CO)
**Credits**: 3 | **Type**: Core

DBMS architecture, relational model, SQL, normalization, database security, and transaction/query processing.

#### Key Syllabus Units:
1. **Introduction**
2. **Database System Concepts and Architecture (E-R model)**
3. **Relational Model**
4. **SQL (incl. PL/SQL)**
5. **Integrity Constraints**
6. **Normalization (1NF-5NF, BCNF)**
7. **Database Security**
8. **Transaction and Query Processing (ACID, concurrency, WAL)**
9. **Backup and Recovery**

---

### Programming in JAVA (BIT255CO)
**Credits**: 3 | **Type**: Core

Core Java OOP, GUI programming, file I/O, JDBC, socket programming, and Servlet/JSP.

#### Key Syllabus Units:
1. **Introduction to Java**
2. **Applet Programming**
3. **GUI Programming (AWT/Swing)**
4. **Java IO**
5. **JDBC**
6. **Socket Programming**
7. **Distributed Application (RMI)**
8. **Overview of Servlet and JSP**

---

### Project-IV (BIT256CO)
**Credits**: 2 | **Type**: Project / Practical

Group application software project (up to 3 students) developed in Java, with proposal, mid-term, and final presentation.

#### Key Syllabus Units:
1. **Title Identification & Proposal Writing**
2. **Mid-Term Presentation**
3. **Pre-Final Submission & Final Presentation**
