## Detailed Course Outlines

### Network Programming (BIT401CO)
**Credits**: 3 | **Type**: Core

Client-server socket programming — TCP/UDP sockets, I/O multiplexing, broadcast/multicast, and raw sockets in C/Unix.

#### Key Syllabus Units:
1. **Introduction to Network Programming (Client/Server Model)**
2. **Elementary Operating System Calls (fork, exec, wait, IPC)**
3. **TCP/UDP Transport Layer Protocols**
4. **Elementary Socket Calls (socket, bind, connect, accept)**
5. **Elementary TCP-UDP Socket Calls (sendto, recvfrom)**
6. **I/O Multiplexing (select, poll, shutdown)**
7. **Socket Options (getsockopt, setsockopt, SO_REUSEADDR)**
8. **Name and Address Conversion (DNS, gethostbyname, getaddrinfo)**
9. **Unix Domain Protocols (socketpair, stream/datagram)**
10. **Daemon Processes and inetd Superserver**
11. **Broadcast and Multicast**
12. **IP Layers and Raw Sockets (ping implementation)**

4. **e-Government Readiness Framework**
5. **Security for e-Government (Security Standards)**

8. **Citizen-Centric Remote Online Digital Governance (CRM)**

10. **Case Studies: Nepal (GIDC, Cyber Law), India, and Global Systems**

### Machine Learning (Track A) (BIT421CO)
**Credits**: 3 | **Type**: Elective

Theoretical concepts and practical implementations of supervised regression/classification, decision trees, model tuning, text mining, and deep neural networks in Python.

#### Key Syllabus Units:
1. **Introduction to Machine Learning (Components & Frameworks)**
2. **Supervised Learning: Regression, Classification, Decision Trees**
3. **Unsupervised Learning (k-means, k-modes)**
4. **Model Diagnosis and Tuning (Bias/Variance, Cross-Validation)**
5. **Text Mining (Preprocessing, TF-IDF, Exploration)**
6. **Deep Learning (Feedforward, CNNs, RNNs)**

### Internship (BIT403CO)
**Credits**: 3 | **Type**: Project / Practical

45-hour supervised internship at a partner organization (bank, hospital, software company, telecom, or government IT unit), evaluated via proposal defense, mid-term, and end-term report.

#### Key Syllabus Units:
1. **Proposal Defense & Organization Placement (10%)**
2. **Mid-Term Progress Review & System Design (30%)**
3. **System Analysis, Implementation & Testing**
4. **Final Internship Report (APA Format) & Viva (60%)**
