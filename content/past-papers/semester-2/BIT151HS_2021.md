### Question 1
Find the solution of the differential equation:
$$(x + 1) \, dy + (y - 1) \, dx = 0$$

#### 💡 Core Theory & Formulas Needed
1. **Separation of Variables:** Group terms so that $y$-terms multiply $dy$ and $x$-terms multiply $dx$:
   $$\frac{dy}{y - 1} + \frac{dx}{x + 1} = 0$$
2. **Logarithmic Integration Rule:** $\int \frac{du}{u} = \ln|u| + C$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Separate the variables**
Divide throughout by $(x + 1)(y - 1)$:
$$\frac{dy}{y - 1} + \frac{dx}{x + 1} = 0$$

**Step 2: Integrate both terms**
$$\int \frac{dy}{y - 1} + \int \frac{dx}{x + 1} = C_1$$
$$\ln|y - 1| + \ln|x + 1| = \ln C$$

**Step 3: Combine logarithmic terms**
$$\ln|(x + 1)(y - 1)| = \ln C \implies (x + 1)(y - 1) = C$$

**Final Answer:**
$$(x + 1)(y - 1) = C \quad \text{or} \quad xy - x + y - 1 = C$$

### Question 2
Find the inverse Laplace transform of:
$$\frac{1}{s^2 + 3s + 2}$$

#### 💡 Core Theory & Formulas Needed
1. **Partial Fractions:** Decompose the rational expression into linear denominators.
2. **Standard Inverse Laplace Transform:** $\mathcal{L}^{-1}\left\{\frac{1}{s - a}\right\} = e^{at}$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Factor the denominator**
$$s^2 + 3s + 2 = (s + 1)(s + 2)$$
$$\frac{1}{(s + 1)(s + 2)} = \frac{A}{s + 1} + \frac{B}{s + 2}$$

**Step 2: Find constants $A$ and $B$ (Cover-up Method)**
- For $A$ (set $s = -1$): $A = \frac{1}{-1 + 2} = 1$.
- For $B$ (set $s = -2$): $B = \frac{1}{-2 + 1} = -1$.
$$\frac{1}{s^2 + 3s + 2} = \frac{1}{s + 1} - \frac{1}{s + 2}$$

**Step 3: Apply the linearity of Inverse Laplace Transform**
$$\mathcal{L}^{-1}\left\{ \frac{1}{s + 1} - \frac{1}{s + 2} \right\} = \mathcal{L}^{-1}\left\{ \frac{1}{s - (-1)} \right\} - \mathcal{L}^{-1}\left\{ \frac{1}{s - (-2)} \right\}$$
$$= e^{-t} - e^{-2t}$$

**Final Answer:**
$$\mathcal{L}^{-1}\left\{\frac{1}{s^2 + 3s + 2}\right\} = e^{-t} - e^{-2t}$$

### Question 3
Express $f(z) = \log z$ in the form $u(x, y) + i v(x, y)$.

#### 💡 Core Theory & Formulas Needed
1. Complex number in polar form: $z = x + iy = r e^{i\theta}$, where modulus $r = |z| = \sqrt{x^2 + y^2}$ and principal argument $\theta = \text{Arg}(z) = \arctan\left(\frac{y}{x}\right)$.
2. Complex logarithm: $\log z = \ln|z| + i \text{Arg}(z)$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Write $z$ in polar form**
$$z = r e^{i\theta} = \sqrt{x^2 + y^2} \, e^{i \arctan(y/x)}$$

**Step 2: Take the natural logarithm**
$$\log z = \ln(r e^{i\theta}) = \ln r + \ln(e^{i\theta}) = \ln r + i\theta$$

**Step 3: Substitute $r$ and $\theta$ in terms of $x$ and $y$**
$$\log z = \ln\left(\sqrt{x^2 + y^2}\right) + i \arctan\left(\frac{y}{x}\right) = \frac{1}{2}\ln(x^2 + y^2) + i \arctan\left(\frac{y}{x}\right)$$

**Step 4: Identify real and imaginary parts**
$$u(x, y) = \frac{1}{2}\ln(x^2 + y^2), \quad v(x, y) = \arctan\left(\frac{y}{x}\right)$$

### Question 4
Find the Fourier expansion of the function in the interval $0 \le x \le 2\pi$:
$$f(x) = 2x$$

#### 💡 Core Theory & Formulas Needed
In interval $[0, 2\pi]$ with period $2L = 2\pi \implies L = \pi$:
1. $a_0 = \frac{1}{\pi} \int_0^{2\pi} f(x) \, dx$.
2. $a_n = \frac{1}{\pi} \int_0^{2\pi} f(x) \cos(nx) \, dx$.
3. $b_n = \frac{1}{\pi} \int_0^{2\pi} f(x) \sin(nx) \, dx$.
4. Fourier series: $f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty (a_n \cos nx + b_n \sin nx)$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Calculate $a_0$**
$$a_0 = \frac{1}{\pi} \int_0^{2\pi} 2x \, dx = \frac{1}{\pi} \left[ x^2 \right]_0^{2\pi} = \frac{(2\pi)^2}{\pi} = \frac{4\pi^2}{\pi} = 4\pi$$

**Step 2: Calculate $a_n$**
$$a_n = \frac{1}{\pi} \int_0^{2\pi} 2x \cos(nx) \, dx = \frac{2}{\pi} \left[ \frac{x \sin(nx)}{n} + \frac{\cos(nx)}{n^2} \right]_0^{2\pi}$$
Since $\sin(2n\pi) = \sin(0) = 0$ and $\cos(2n\pi) = \cos(0) = 1$:
$$a_n = \frac{2}{\pi} \left( 0 + \frac{1}{n^2} - 0 - \frac{1}{n^2} \right) = 0$$

**Step 3: Calculate $b_n$**
$$b_n = \frac{1}{\pi} \int_0^{2\pi} 2x \sin(nx) \, dx = \frac{2}{\pi} \left[ -\frac{x \cos(nx)}{n} + \frac{\sin(nx)}{n^2} \right]_0^{2\pi}$$
$$b_n = \frac{2}{\pi} \left( -\frac{2\pi \cos(2n\pi)}{n} + 0 - 0 \right) = \frac{2}{\pi} \left( -\frac{2\pi(1)}{n} \right) = -\frac{4}{n}$$

**Step 4: Assemble the Fourier Series**
$$f(x) = \frac{4\pi}{2} + \sum_{n=1}^\infty \left( 0 \cdot \cos(nx) - \frac{4}{n} \sin(nx) \right)$$
$$2x = 2\pi - 4 \sum_{n=1}^\infty \frac{\sin(nx)}{n} = 2\pi - 4\left( \sin x + \frac{\sin 2x}{2} + \frac{\sin 3x}{3} + \dots \right)$$

### Question 5
Find the general solution of the partial differential equation:
$$a p + b q = c$$

#### 💡 Core Theory & Formulas Needed
1. **Quasi-linear first-order PDE:** $P p + Q q = R$, where $p = \frac{\partial z}{\partial x}$ and $q = \frac{\partial z}{\partial y}$.
2. **Lagrange's Auxiliary Equations:**
   $$\frac{dx}{P} = \frac{dy}{Q} = \frac{dz}{R} \implies \frac{dx}{a} = \frac{dy}{b} = \frac{dz}{c}$$

#### 📝 Step-by-Step Complete Solution

**Step 1: Set up Lagrange's Auxiliary Equations**
$$\frac{dx}{a} = \frac{dy}{b} = \frac{dz}{c}$$

**Step 2: Solve the first pair $\frac{dx}{a} = \frac{dy}{b}$**
$$b \, dx - a \, dy = 0 \implies \int b \, dx - \int a \, dy = c_1$$
$$u(x, y, z) = bx - ay = c_1$$

**Step 3: Solve the second pair $\frac{dx}{a} = \frac{dz}{c}$**
$$c \, dx - a \, dz = 0 \implies \int c \, dx - \int a \, dz = c_2$$
$$v(x, y, z) = cx - az = c_2$$

**Step 4: Form the general solution**
The general solution is $\Phi(u, v) = 0$ or $v = f(u)$:
$$cx - az = f(bx - ay) \implies z = \frac{c}{a}x - \frac{1}{a} f(bx - ay)$$
where $f$ (or $\Phi$) is an arbitrary function.

### Question 6
Evaluate $\oint_C f(z) \, dz$, where $f(z) = \frac{1}{z - a}$, $C$ is the circle with centre at $a$ and radius $r$.

#### 💡 Core Theory & Formulas Needed
1. **Parametrization of a Circle:** A circle of radius $r$ centered at $z = a$ is given by:
   $$z - a = r e^{i\theta} \implies z = a + r e^{i\theta}, \quad 0 \le \theta \le 2\pi$$
   $$dz = i r e^{i\theta} \, d\theta$$
2. Alternatively, by **Cauchy's Residue Theorem**: $\oint_C f(z) \, dz = 2\pi i \cdot \text{Res}(f, a)$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Substitute the parametrization**
$$\oint_C \frac{1}{z - a} \, dz = \int_0^{2\pi} \frac{1}{r e^{i\theta}} (i r e^{i\theta} \, d\theta)$$

**Step 2: Simplify and integrate**
$$= i \int_0^{2\pi} d\theta = i [\theta]_0^{2\pi} = i(2\pi - 0) = 2\pi i$$

**Final Answer:**
$$\oint_C \frac{1}{z - a} \, dz = 2\pi i$$

### Question 7
Calculate the residue of:
$$f(z) = \frac{1}{z^2 + z}$$

#### 💡 Core Theory & Formulas Needed
1. Factor the denominator to find singularities: $z^2 + z = z(z + 1) = 0 \implies z = 0, z = -1$ (both are simple poles).
2. Residue at a simple pole $z_0$: $\text{Res}(f, z_0) = \lim_{z \to z_0} (z - z_0) f(z)$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Residue at pole $z = 0$**
$$\text{Res}(f, 0) = \lim_{z \to 0} z \cdot \frac{1}{z(z + 1)} = \lim_{z \to 0} \frac{1}{z + 1} = \frac{1}{0 + 1} = 1$$

**Step 2: Residue at pole $z = -1$**
$$\text{Res}(f, -1) = \lim_{z \to -1} (z + 1) \cdot \frac{1}{z(z + 1)} = \lim_{z \to -1} \frac{1}{z} = \frac{1}{-1} = -1$$

**Final Answer:**
$$\text{Res}(f, 0) = 1, \quad \text{Res}(f, -1) = -1$$

#### 💡 Core Theory & Formulas Needed

2. **First Shifting Property:** If $\mathcal{L}\{f(t)\} = F(s)$, then:

### Question 11
Solve the differential equation:
$$\frac{dy}{dx} = \frac{2xy}{x^2 - y^2}$$

#### 💡 Core Theory & Formulas Needed
1. **Homogeneous Differential Equation:** Both numerator $2xy$ and denominator $x^2 - y^2$ are homogeneous polynomials of degree 2.
2. **Standard Substitution:** Substitute $y = vx \implies \frac{dy}{dx} = v + x \frac{dv}{dx}$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Substitute $y = vx$**
$$v + x \frac{dv}{dx} = \frac{2x(vx)}{x^2 - (vx)^2} = \frac{2v x^2}{x^2(1 - v^2)} = \frac{2v}{1 - v^2}$$

**Step 2: Isolate $x \frac{dv}{dx}$**
$$x \frac{dv}{dx} = \frac{2v}{1 - v^2} - v = \frac{2v - v(1 - v^2)}{1 - v^2} = \frac{2v - v + v^3}{1 - v^2} = \frac{v + v^3}{1 - v^2} = \frac{v(1 + v^2)}{1 - v^2}$$

**Step 3: Separate variables**
$$\frac{1 - v^2}{v(1 + v^2)} \, dv = \frac{dx}{x}$$

**Step 4: Resolve left side into partial fractions**
$$\frac{1 - v^2}{v(1 + v^2)} = \frac{A}{v} + \frac{Bv + C}{1 + v^2} \implies 1 - v^2 = A(1 + v^2) + (Bv + C)v$$
- Setting $v = 0 \implies A = 1$.
- Equating coefficients of $v^2$: $-1 = A + B \implies -1 = 1 + B \implies B = -2$.
- Equating coefficients of $v$: $C = 0$.
$$\frac{1 - v^2}{v(1 + v^2)} = \frac{1}{v} - \frac{2v}{1 + v^2}$$

**Step 5: Integrate both sides**
$$\int \left( \frac{1}{v} - \frac{2v}{1 + v^2} \right) dv = \int \frac{dx}{x}$$
$$\ln|v| - \ln(1 + v^2) = \ln|x| + \ln C$$
$$\ln\left| \frac{v}{1 + v^2} \right| = \ln|C x| \implies \frac{v}{1 + v^2} = C x$$

**Step 6: Substitute back $v = \frac{y}{x}$**
$$\frac{\frac{y}{x}}{1 + \frac{y^2}{x^2}} = C x \implies \frac{\frac{y}{x}}{\frac{x^2 + y^2}{x^2}} = C x \implies \frac{x y}{x^2 + y^2} = C x$$
Divide both sides by $x$ (for $x \ne 0$):
$$\frac{y}{x^2 + y^2} = C \implies x^2 + y^2 = c_1 y \quad \left(\text{where } c_1 = \frac{1}{C}\right)$$

**Final Answer:**
$$x^2 + y^2 - c_1 y = 0$$
*(This represents a family of circles passing through the origin with centers on the $y$-axis).*

### Question 12
Solve the second order differential equation:
$$\frac{d^2 y}{dx^2} - 2 \frac{dy}{dx} + 4y = e^x \sin x$$

#### 💡 Core Theory & Formulas Needed
1. **Complementary Function ($y_c$):** Roots of $m^2 - 2m + 4 = 0$.
2. **Exponential Shift Theorem for Particular Integral ($y_p$):**
   $$\frac{1}{f(D)} [e^{ax} V(x)] = e^{ax} \frac{1}{f(D + a)} V(x)$$

#### 📝 Step-by-Step Complete Solution

**Step 1: Complementary function ($y_c$)**
Auxiliary equation:
$$m^2 - 2m + 4 = 0 \implies m = \frac{2 \pm \sqrt{4 - 16}}{2} = \frac{2 \pm 2i\sqrt{3}}{2} = 1 \pm i\sqrt{3}$$
$$y_c = e^x \left( c_1 \cos(\sqrt{3}x) + c_2 \sin(\sqrt{3}x) \right)$$

**Step 2: Particular integral ($y_p$)**
$$y_p = \frac{1}{D^2 - 2D + 4} (e^x \sin x)$$
Apply the exponential shift rule (replace $D$ with $D + 1$):
$$y_p = e^x \frac{1}{(D + 1)^2 - 2(D + 1) + 4} \sin x = e^x \frac{1}{(D^2 + 2D + 1) - 2D - 2 + 4} \sin x$$
$$= e^x \frac{1}{D^2 + 3} \sin x$$

**Step 3: Evaluate $\frac{1}{D^2 + 3} \sin x$**
Replace $D^2$ with $-1^2 = -1$:
$$y_p = e^x \frac{\sin x}{-1 + 3} = \frac{e^x \sin x}{2}$$

**Step 4: General Solution**
$$y = y_c + y_p = e^x \left( c_1 \cos(\sqrt{3}x) + c_2 \sin(\sqrt{3}x) \right) + \frac{e^x \sin x}{2}$$

### Question 13
Solve:
$$x \, dy - y \, dx = \sqrt{x^2 + y^2} \, dx$$

#### 💡 Core Theory & Formulas Needed
1. Rearrange to: $\frac{dy}{dx} = \frac{y + \sqrt{x^2 + y^2}}{x} = \frac{y}{x} + \sqrt{1 + \left(\frac{y}{x}\right)^2}$.
2. Homogeneous substitution: $y = vx \implies \frac{dy}{dx} = v + x \frac{dv}{dx}$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Substitute $y = vx$**
$$v + x \frac{dv}{dx} = v + \sqrt{1 + v^2}$$
Subtract $v$ from both sides:
$$x \frac{dv}{dx} = \sqrt{1 + v^2}$$

**Step 2: Separate variables and integrate**
$$\frac{dv}{\sqrt{1 + v^2}} = \frac{dx}{x}$$
$$\int \frac{dv}{\sqrt{1 + v^2}} = \int \frac{dx}{x}$$
$$\ln|v + \sqrt{1 + v^2}| = \ln|x| + \ln C$$
$$v + \sqrt{1 + v^2} = C x$$

**Step 3: Substitute back $v = \frac{y}{x}$**
$$\frac{y}{x} + \sqrt{1 + \frac{y^2}{x^2}} = C x \implies \frac{y + \sqrt{x^2 + y^2}}{x} = C x$$
$$y + \sqrt{x^2 + y^2} = C x^2$$

### Question 14
Find the Laplace transform of:
$$t e^{-t} \cos t$$

#### 💡 Core Theory & Formulas Needed
1. Standard transform: $\mathcal{L}\{\cos t\} = \frac{s}{s^2 + 1}$.
2. Multiplication by $t$ rule: $\mathcal{L}\{t f(t)\} = -\frac{d}{ds} F(s)$.
3. First Shifting Theorem: $\mathcal{L}\{e^{at} g(t)\} = G(s - a)$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Find transform of $t \cos t$**
$$\mathcal{L}\{\cos t\} = \frac{s}{s^2 + 1}$$
$$\mathcal{L}\{t \cos t\} = -\frac{d}{ds}\left( \frac{s}{s^2 + 1} \right) = -\frac{(s^2 + 1)(1) - s(2s)}{(s^2 + 1)^2} = -\frac{1 - s^2}{(s^2 + 1)^2} = \frac{s^2 - 1}{(s^2 + 1)^2}$$

**Step 2: Apply First Shifting Theorem for $e^{-t}$ ($s \to s + 1$)**
$$\mathcal{L}\{e^{-t} (t \cos t)\} = \frac{(s + 1)^2 - 1}{\left[ (s + 1)^2 + 1 \right]^2}$$

**Step 3: Simplify the numerator and denominator**
$$\text{Numerator} = s^2 + 2s + 1 - 1 = s^2 + 2s$$
$$\text{Denominator} = (s^2 + 2s + 1 + 1)^2 = (s^2 + 2s + 2)^2$$

**Final Answer:**
$$\mathcal{L}\{t e^{-t} \cos t\} = \frac{s^2 + 2s}{(s^2 + 2s + 2)^2}$$

### Question 16
Expand the function $f(x) = x^2, 0 \le x \le \pi$ in a Fourier cosine series and deduce that:
$$\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}$$

#### 💡 Core Theory & Formulas Needed
1. Half-range Fourier cosine series on $[0, \pi]$:
   $$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty a_n \cos(nx)$$
   where $a_0 = \frac{2}{\pi} \int_0^\pi f(x) \, dx$ and $a_n = \frac{2}{\pi} \int_0^\pi f(x) \cos(nx) \, dx$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Calculate $a_0$**
$$a_0 = \frac{2}{\pi} \int_0^\pi x^2 \, dx = \frac{2}{\pi} \left[ \frac{x^3}{3} \right]_0^\pi = \frac{2\pi^3}{3\pi} = \frac{2\pi^2}{3}$$

**Step 2: Calculate $a_n$ by Tabular / Repeated Integration by Parts**
$$a_n = \frac{2}{\pi} \int_0^\pi x^2 \cos(nx) \, dx$$
$$\int x^2 \cos(nx) \, dx = x^2 \frac{\sin(nx)}{n} - (2x)\left(-\frac{\cos(nx)}{n^2}\right) + (2)\left(-\frac{\sin(nx)}{n^3}\right)$$
$$= \left[ \frac{x^2 \sin(nx)}{n} + \frac{2x \cos(nx)}{n^2} - \frac{2 \sin(nx)}{n^3} \right]_0^\pi$$
Evaluating at limits (since $\sin(n\pi) = \sin 0 = 0$):
$$= \left( 0 + \frac{2\pi \cos(n\pi)}{n^2} - 0 \right) - (0) = \frac{2\pi (-1)^n}{n^2}$$
Multiplying by $\frac{2}{\pi}$:
$$a_n = \frac{2}{\pi} \cdot \frac{2\pi (-1)^n}{n^2} = \frac{4(-1)^n}{n^2}$$

**Step 3: Assemble the Fourier cosine series**
$$x^2 = \frac{a_0}{2} + \sum_{n=1}^\infty a_n \cos(nx) = \frac{\pi^2}{3} + 4 \sum_{n=1}^\infty \frac{(-1)^n \cos(nx)}{n^2}$$

**Step 4: Deduce the sum $\sum_{n=1}^\infty \frac{1}{n^2}$ by setting $x = \pi$**
At $x = \pi$, $\cos(n\pi) = (-1)^n$:
$$\pi^2 = \frac{\pi^2}{3} + 4 \sum_{n=1}^\infty \frac{(-1)^n (-1)^n}{n^2} = \frac{\pi^2}{3} + 4 \sum_{n=1}^\infty \frac{1}{n^2}$$
$$\pi^2 - \frac{\pi^2}{3} = 4 \sum_{n=1}^\infty \frac{1}{n^2} \implies \frac{2\pi^2}{3} = 4 \sum_{n=1}^\infty \frac{1}{n^2}$$
Divide both sides by $4$:
$$\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}$$

### Question 18
Obtain the Laurent Series for:
$$f(z) = \frac{1}{(1 - z)(z + 2)} \quad \text{in the domain } 1 < |z| < 2$$

#### 💡 Core Theory & Formulas Needed
1. Partial fraction expansion: $\frac{1}{(1 - z)(z + 2)} = \frac{1/3}{1 - z} + \frac{1/3}{z + 2}$.
2. Geometric series: $\frac{1}{1 - w} = \sum_{n=0}^\infty w^n$ valid for $|w| < 1$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Partial fractions**
$$\frac{1}{(1 - z)(z + 2)} = \frac{A}{1 - z} + \frac{B}{z + 2}$$
$$1 = A(z + 2) + B(1 - z)$$
- Set $z = 1 \implies 1 = 3A \implies A = \frac{1}{3}$.
- Set $z = -2 \implies 1 = 3B \implies B = \frac{1}{3}$.
$$f(z) = \frac{1}{3}\frac{1}{1 - z} + \frac{1}{3}\frac{1}{z + 2}$$

**Step 2: Expand the first term for $|z| > 1$**
Since $|z| > 1 \implies |1/z| < 1$:
$$\frac{1}{3(1 - z)} = -\frac{1}{3z\left(1 - \frac{1}{z}\right)} = -\frac{1}{3z} \sum_{n=0}^\infty \left(\frac{1}{z}\right)^n = -\frac{1}{3} \sum_{n=0}^\infty \frac{1}{z^{n+1}} = -\frac{1}{3} \sum_{n=1}^\infty \frac{1}{z^n}$$

**Step 3: Expand the second term for $|z| < 2$**
Since $|z| < 2 \implies |z/2| < 1$:
$$\frac{1}{3(z + 2)} = \frac{1}{6\left(1 + \frac{z}{2}\right)} = \frac{1}{6} \sum_{n=0}^\infty (-1)^n \left(\frac{z}{2}\right)^n = \sum_{n=0}^\infty \frac{(-1)^n z^n}{3 \cdot 2^{n+1}}$$

**Step 4: Combine into the complete Laurent series**
$$f(z) = -\frac{1}{3}\sum_{n=1}^\infty \frac{1}{z^n} + \sum_{n=0}^\infty \frac{(-1)^n z^n}{3 \cdot 2^{n+1}}$$
$$f(z) = \dots - \frac{1}{3z^2} - \frac{1}{3z} + \frac{1}{6} - \frac{z}{12} + \frac{z^2}{24} - \dots$$

Solve the partial differential equation:

   $$dz = a \, dx - \frac{a^2}{y} \, dy$$

### Question 20
Solve the differential equation by the method of Laplace transform:
$$\frac{d^2 y}{dt^2} + 2 \frac{dy}{dt} + 5y = e^{-t} \sin t, \quad y(0) = 0, \quad y'(0) = 1$$

#### 💡 Core Theory & Formulas Needed
1. $\mathcal{L}\{y''\} = s^2 Y(s) - s y(0) - y'(0)$.
2. $\mathcal{L}\{y'\} = s Y(s) - y(0)$.
3. $\mathcal{L}\{e^{-t}\sin t\} = \frac{1}{(s + 1)^2 + 1} = \frac{1}{s^2 + 2s + 2}$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Take the Laplace transform of both sides**
$$(s^2 Y - s(0) - 1) + 2(s Y - 0) + 5Y = \frac{1}{(s + 1)^2 + 1}$$
$$(s^2 + 2s + 5)Y - 1 = \frac{1}{s^2 + 2s + 2}$$

**Step 2: Solve algebraically for $Y(s)$**
$$(s^2 + 2s + 5)Y = 1 + \frac{1}{s^2 + 2s + 2} = \frac{s^2 + 2s + 3}{s^2 + 2s + 2}$$
$$Y(s) = \frac{s^2 + 2s + 3}{(s^2 + 2s + 5)(s^2 + 2s + 2)}$$

**Step 3: Partial fraction decomposition**
Notice that $s^2 + 2s$ is a common block. Let $u = s^2 + 2s$:
$$\frac{u + 3}{(u + 5)(u + 2)} = \frac{A}{u + 5} + \frac{B}{u + 2}$$
- $u = -5 \implies A = \frac{-5 + 3}{-5 + 2} = \frac{-2}{-3} = \frac{2}{3}$.
- $u = -2 \implies B = \frac{-2 + 3}{-2 + 5} = \frac{1}{3}$.
Therefore:
$$Y(s) = \frac{2/3}{s^2 + 2s + 5} + \frac{1/3}{s^2 + 2s + 2}$$

**Step 4: Complete the square in the denominators**
$$s^2 + 2s + 5 = (s + 1)^2 + 4 = (s + 1)^2 + 2^2$$
$$s^2 + 2s + 2 = (s + 1)^2 + 1 = (s + 1)^2 + 1^2$$
Rewrite $Y(s)$:
$$Y(s) = \frac{2}{3} \cdot \frac{1}{2} \cdot \frac{2}{(s + 1)^2 + 2^2} + \frac{1}{3} \cdot \frac{1}{(s + 1)^2 + 1^2}$$
$$= \frac{1}{3} \cdot \frac{2}{(s + 1)^2 + 2^2} + \frac{1}{3} \cdot \frac{1}{(s + 1)^2 + 1^2}$$

**Step 5: Apply inverse Laplace transform**
Recall $\mathcal{L}^{-1}\left\{\frac{\omega}{(s + a)^2 + \omega^2}\right\} = e^{-at} \sin(\omega t)$:
$$y(t) = \frac{1}{3} e^{-t} \sin 2t + \frac{1}{3} e^{-t} \sin t = \frac{1}{3} e^{-t} (\sin 2t + \sin t)$$

#### (b) Find the Fourier sine integral of the function: `[5]`
$$f(x) = \begin{cases} x^2, & \text{for } 0 < x < b \\ 0, & \text{for } x > b \end{cases}$$

#### 💡 Core Theory & Formulas Needed
1. **Fourier Sine Integral Representation:**
   $$f(x) = \frac{2}{\pi} \int_0^\infty B(\omega) \sin(\omega x) \, d\omega$$
   where:
   $$B(\omega) = \int_0^\infty f(x) \sin(\omega x) \, dx = \int_0^b x^2 \sin(\omega x) \, dx$$

#### 📝 Step-by-Step Complete Solution

**Step 1: Set up integration by parts (Bernoulli's Formula)**
$$\int u v \, dx = u v_1 - u' v_2 + u'' v_3$$
Let $u = x^2 \implies u' = 2x \implies u'' = 2 \implies u''' = 0$.
Let $v = \sin(\omega x) \implies v_1 = -\frac{\cos(\omega x)}{\omega} \implies v_2 = -\frac{\sin(\omega x)}{\omega^2} \implies v_3 = \frac{\cos(\omega x)}{\omega^3}$.

**Step 2: Evaluate the definite integral**
$$B(\omega) = \left[ -x^2 \frac{\cos(\omega x)}{\omega} - (2x)\left(-\frac{\sin(\omega x)}{\omega^2}\right) + (2)\left(\frac{\cos(\omega x)}{\omega^3}\right) \right]_0^b$$
$$= \left[ -\frac{x^2 \cos(\omega x)}{\omega} + \frac{2x \sin(\omega x)}{\omega^2} + \frac{2 \cos(\omega x)}{\omega^3} \right]_0^b$$
Substitute upper limit $x = b$:
$$= -\frac{b^2 \cos(\omega b)}{\omega} + \frac{2b \sin(\omega b)}{\omega^2} + \frac{2 \cos(\omega b)}{\omega^3}$$
Substitute lower limit $x = 0$:
$$= -\left( 0 + 0 + \frac{2}{\omega^3} \right) = -\frac{2}{\omega^3}$$
Combine:
$$B(\omega) = \frac{2\cos(\omega b) - 2}{\omega^3} + \frac{2b \sin(\omega b)}{\omega^2} - \frac{b^2 \cos(\omega b)}{\omega}$$

**Step 3: Write the Fourier sine integral**
$$f(x) = \frac{2}{\pi} \int_0^\infty \left[ \frac{2\cos(\omega b) - 2}{\omega^3} + \frac{2b \sin(\omega b)}{\omega^2} - \frac{b^2 \cos(\omega b)}{\omega} \right] \sin(\omega x) \, d\omega$$

### Question 22
Obtain the general solution of the one-dimensional wave equation:
$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}$$
using the method of separation of variables. `[10]`

#### 💡 Core Theory & Formulas Needed
1. Wave equation describes transverse displacement $u(x, t)$ of an elastic string with fixed ends.
2. Trial solution: $u(x, t) = X(x) T(t)$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Separate the variables**
Let $u(x, t) = X(x) T(t)$.
Compute derivatives:
$$\frac{\partial^2 u}{\partial t^2} = X(x) T''(t), \quad \frac{\partial^2 u}{\partial x^2} = X''(x) T(t)$$
Substitute into the wave equation:
$$X T'' = c^2 X'' T$$
Divide throughout by $c^2 X T$:
$$\frac{X''}{X} = \frac{T''}{c^2 T} = k \quad (\text{separation constant})$$

**Step 2: Analyze the three cases for constant $k$**

- **Case 1: $k = 0$**
  $$X'' = 0 \implies X(x) = c_1 x + c_2$$
  $$T'' = 0 \implies T(t) = c_3 t + c_4$$
  $$u(x, t) = (c_1 x + c_2)(c_3 t + c_4)$$
  *(Non-periodic, does not represent wave motion).*

- **Case 2: $k = p^2 > 0$**
  $$X'' - p^2 X = 0 \implies X(x) = c_1 e^{px} + c_2 e^{-px}$$
  $$T'' - p^2 c^2 T = 0 \implies T(t) = c_3 e^{pct} + c_4 e^{-pct}$$
  *(Exponentially grows without bound as $t \to \infty$, physically invalid for bounded strings).*

- **Case 3: $k = -p^2 < 0$ (Physically Oscillatory Solution)**
  $$X'' + p^2 X = 0 \implies X(x) = c_1 \cos(px) + c_2 \sin(px)$$
  $$T'' + p^2 c^2 T = 0 \implies T(t) = c_3 \cos(pct) + c_4 \sin(pct)$$
  The product solution is:
  $$u(x, t) = [c_1 \cos(px) + c_2 \sin(px)][c_3 \cos(pct) + c_4 \sin(pct)]$$

**Step 3: Apply Boundary Conditions for a string of length $L$ fixed at both ends**
1. **At $x = 0$:** $u(0, t) = 0 \implies c_1 = 0$.
   $$X(x) = c_2 \sin(px)$$
2. **At $x = L$:** $u(L, t) = 0 \implies c_2 \sin(pL) = 0$.
   For a non-trivial solution ($c_2 \ne 0$):
   $$\sin(pL) = 0 \implies pL = n\pi \implies p_n = \frac{n\pi}{L}, \quad n = 1, 2, 3, \dots$$

**Step 4: Form the general solution by Principle of Superposition**
For each mode $n$, the solution is:
$$u_n(x, t) = \left[ A_n \cos\left(\frac{n\pi c t}{L}\right) + B_n \sin\left(\frac{n\pi c t}{L}\right) \right] \sin\left(\frac{n\pi x}{L}\right)$$
By linear superposition of all normal modes:
$$u(x, t) = \sum_{n=1}^\infty \left[ A_n \cos\left(\frac{n\pi c t}{L}\right) + B_n \sin\left(\frac{n\pi c t}{L}\right) \right] \sin\left(\frac{n\pi x}{L}\right)$$
where coefficients $A_n, B_n$ are determined by initial conditions (initial shape $u(x, 0)$ and velocity $u_t(x, 0)$) via Fourier sine series.
