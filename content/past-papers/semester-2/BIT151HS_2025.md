### 1. Evaluate:
$$\int_0^a \int_0^b (x^2 + y^2) \, dx \, dy$$

**Solution:**
Let the given double integral be:
$$I = \int_0^a \int_0^b (x^2 + y^2) \, dx \, dy$$

First, evaluate the inner integral with respect to $x$, treating $y$ as a constant:
$$\int_0^b (x^2 + y^2) \, dx = \left[ \frac{x^3}{3} + y^2 x \right]_{x=0}^{x=b} = \left( \frac{b^3}{3} + b y^2 \right) - 0 = \frac{b^3}{3} + b y^2$$

Now, evaluate the outer integral with respect to $y$:
$$I = \int_0^a \left( \frac{b^3}{3} + b y^2 \right) \, dy = \left[ \frac{b^3 y}{3} + \frac{b y^3}{3} \right]_{y=0}^{y=a}$$
$$I = \left( \frac{a b^3}{3} + \frac{a^3 b}{3} \right) - 0 = \frac{ab(a^2 + b^2)}{3}$$

$$\therefore \int_0^a \int_0^b (x^2 + y^2) \, dx \, dy = \frac{ab(a^2 + b^2)}{3}$$

### 2. Evaluate:
$$\int_0^1 \int_0^2 \int_0^3 xyz \, dx \, dy \, dz$$

**Solution:**
Since all limits of integration are independent constants and the integrand $f(x, y, z) = x \cdot y \cdot z$ is separable, we factor the triple integral into the product of three independent single integrals:
$$I = \left( \int_0^3 x \, dx \right) \left( \int_0^2 y \, dy \right) \left( \int_0^1 z \, dz \right)$$

Evaluating each integral separately:
1. $\int_0^3 x \, dx = \left[ \frac{x^2}{2} \right]_0^3 = \frac{9}{2}$
2. $\int_0^2 y \, dy = \left[ \frac{y^2}{2} \right]_0^2 = \frac{4}{2} = 2$
3. $\int_0^1 z \, dz = \left[ \frac{z^2}{2} \right]_0^1 = \frac{1}{2}$

Multiplying the results:
$$I = \frac{9}{2} \times 2 \times \frac{1}{2} = \frac{9}{2} = 4.5$$

$$\therefore \int_0^1 \int_0^2 \int_0^3 xyz \, dx \, dy \, dz = \frac{9}{2}$$

### 3. Solve:
$$\sqrt{1 - x^2} \, dy + \sqrt{1 - y^2} \, dx = 0$$

**Solution:**
Given first-order differential equation:
$$\sqrt{1 - x^2} \, dy + \sqrt{1 - y^2} \, dx = 0$$

Separating the variables by dividing throughout by $\sqrt{1 - x^2}\sqrt{1 - y^2}$:
$$\frac{dy}{\sqrt{1 - y^2}} + \frac{dx}{\sqrt{1 - x^2}} = 0$$

Integrating both sides:
$$\int \frac{dy}{\sqrt{1 - y^2}} + \int \frac{dx}{\sqrt{1 - x^2}} = C$$
$$\sin^{-1} y + \sin^{-1} x = C$$

Taking the sine of both sides:
$$\sin(\sin^{-1} x + \sin^{-1} y) = \sin C$$
Using the addition formula $\sin(A + B) = \sin A \cos B + \cos A \sin B$ where $\sin A = x \implies \cos A = \sqrt{1 - x^2}$ and $\sin B = y \implies \cos B = \sqrt{1 - y^2}$:
$$x \sqrt{1 - y^2} + y \sqrt{1 - x^2} = c \quad (\text{where } c = \sin C)$$

$$\therefore x \sqrt{1 - y^2} + y \sqrt{1 - x^2} = c$$

### 4. Solve:
$$P^2 - y^2 = 0 \quad \text{where } P = \frac{dy}{dx}$$

**Solution:**
The given equation of first order and higher degree is:
$$P^2 - y^2 = 0 \implies (P - y)(P + y) = 0$$

This gives two separate first-order differential equations:
**Case 1:** $P - y = 0 \implies \frac{dy}{dx} = y$
$$\frac{dy}{y} = dx \implies \int \frac{dy}{y} = \int dx \implies \ln|y| = x + c_1 \implies y = C_1 e^x \implies y - C_1 e^x = 0$$

**Case 2:** $P + y = 0 \implies \frac{dy}{dx} = -y$
$$\frac{dy}{y} = -dx \implies \int \frac{dy}{y} = -\int dx \implies \ln|y| = -x + c_2 \implies y = C_2 e^{-x} \implies y - C_2 e^{-x} = 0$$

Combining both factors into a single general solution (using an arbitrary constant $c$):
$$(y - c e^x)(y - c e^{-x}) = 0$$

### 5. Solve:

**Solution:**
Given homogeneous second-order linear differential equation:
$$\frac{d^2 y}{dx^2} - 3 \frac{dy}{dx} + 2y = 0$$

Let $y = e^{mx}$ be a trial solution. The auxiliary (characteristic) equation is:

Since the roots are real and distinct ($m_1 \ne m_2$), the complementary function and general solution is:
$$y = c_1 e^{x} + c_2 e^{2x}$$

### 6. Define even and odd function with examples.

**Solution:**
- **Even Function:**
  A function $f(x)$ is defined to be an **even function** if:
  $$f(-x) = f(x) \quad \text{for all } x \text{ in the domain of } f$$
  The graph of an even function is symmetric with respect to the $y$-axis.
  *Examples:*
  1. $f(x) = x^2 \implies f(-x) = (-x)^2 = x^2 = f(x)$
  2. $f(x) = \cos x \implies f(-x) = \cos(-x) = \cos x = f(x)$
  *Fourier Property:* In the interval $(-L, L)$, the Fourier sine coefficients vanish ($b_n = 0$), resulting in a Fourier cosine series.

- **Odd Function:**
  A function $f(x)$ is defined to be an **odd function** if:
  $$f(-x) = -f(x) \quad \text{for all } x \text{ in the domain of } f$$
  The graph of an odd function has rotational symmetry about the origin $(0, 0)$.
  *Examples:*
  1. $f(x) = x^3 \implies f(-x) = (-x)^3 = -x^3 = -f(x)$
  2. $f(x) = \sin x \implies f(-x) = \sin(-x) = -\sin x = -f(x)$
  *Fourier Property:* In the interval $(-L, L)$, the Fourier cosine coefficients vanish ($a_0 = 0, a_n = 0$), resulting in a Fourier sine series.

- **Real part:** $u(x, y) = e^x \cos y$
- **Imaginary part:** $v(x, y) = e^x \sin y$

### 8. Find the derivative of $z^2$ at $z = z_0$.

**Solution:**
Let $f(z) = z^2$. By the first-principles definition of the complex derivative:
$$f'(z_0) = \lim_{\Delta z \to 0} \frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z}$$

Evaluating the numerator:
$$f(z_0 + \Delta z) = (z_0 + \Delta z)^2 = z_0^2 + 2z_0 \Delta z + (\Delta z)^2$$
$$f(z_0 + \Delta z) - f(z_0) = z_0^2 + 2z_0 \Delta z + (\Delta z)^2 - z_0^2 = 2z_0 \Delta z + (\Delta z)^2$$

Dividing by $\Delta z \ne 0$:
$$\frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z} = \frac{\Delta z (2z_0 + \Delta z)}{\Delta z} = 2z_0 + \Delta z$$

Taking the limit as $\Delta z \to 0$:
$$f'(z_0) = \lim_{\Delta z \to 0} (2z_0 + \Delta z) = 2z_0$$

$$\therefore \left. \frac{d}{dz}(z^2) \right|_{z = z_0} = 2z_0$$

### 9. Find the zeros of the function:
$$f(z) = (z - 3)\sin\left(\frac{1}{z - 2}\right)$$

**Solution:**
The zeros of $f(z)$ are points where $f(z) = 0$.
$$(z - 3)\sin\left(\frac{1}{z - 2}\right) = 0$$

This gives two conditions:
1. $z - 3 = 0 \implies z = 3$ (a simple zero of order 1).
2. $\sin\left(\frac{1}{z - 2}\right) = 0$
   Recall that $\sin w = 0 \iff w = n\pi$ for $n \in \mathbb{Z}$.
   $$\frac{1}{z - 2} = n\pi \quad (n \ne 0 \text{ since } \frac{1}{z-2} \ne 0)$$
   $$z - 2 = \frac{1}{n\pi} \implies z = 2 + \frac{1}{n\pi}, \quad n = \pm 1, \pm 2, \pm 3, \dots$$

**Conclusion:**
The zeros of $f(z)$ are:
$$z = 3 \quad \text{and} \quad z_n = 2 + \frac{1}{n\pi} \quad (n \in \mathbb{Z} \setminus \{0\})$$
*(Note: $z = 2$ is not a zero; it is an isolated essential singularity which is the limit point of these zeros).*

### 10. Determine the order of the pole of the function:
$$f(z) = \frac{\sinh z}{z^5}$$

**Solution:**
Recall the Maclaurin series expansion for the hyperbolic sine function:
$$\sinh z = z + \frac{z^3}{3!} + \frac{z^5}{5!} + \frac{z^7}{7!} + \dots = \sum_{k=0}^\infty \frac{z^{2k+1}}{(2k+1)!}$$

Substituting this series into $f(z)$:
$$f(z) = \frac{1}{z^5} \left( z + \frac{z^3}{6} + \frac{z^5}{120} + \dots \right)$$
$$f(z) = \frac{1}{z^4} + \frac{1}{6z^2} + \frac{1}{120} + \frac{z^2}{5040} + \dots$$

The principal part of the Laurent series of $f(z)$ about $z = 0$ is:
$$\frac{1}{z^4} + \frac{1}{6z^2}$$
The highest negative power of $z$ is $4$.
Therefore, $z = 0$ is a **pole of order 4**.

### 11. Define the Fourier integral of the function. Find the Fourier integral of the function:
$$f(x) = \begin{cases} x, & \text{for } |x| < 1 \\ 0, & \text{for } |x| > 1 \end{cases}$$

**Solution:**
- **Definition of Fourier Integral:**
  If a function $f(x)$ is piecewise smooth in every finite interval and absolutely integrable on the real line, i.e., $\int_{-\infty}^\infty |f(x)| \, dx < \infty$, then $f(x)$ can be represented for all $x$ by the Fourier integral formula:
  $$f(x) = \frac{1}{\pi} \int_0^\infty \left[ A(\lambda) \cos(\lambda x) + B(\lambda) \sin(\lambda x) \right] d\lambda$$
  where the Fourier transform coefficients are:
  $$A(\lambda) = \int_{-\infty}^\infty f(t) \cos(\lambda t) \, dt, \qquad B(\lambda) = \int_{-\infty}^\infty f(t) \sin(\lambda t) \, dt$$

- **Calculation for the Given Function:**
  Here, $f(x) = x$ for $-1 < x < 1$ and $0$ elsewhere.
  Notice that $f(-x) = -x = -f(x)$, so $f(x)$ is an **odd function**.
  - Since $f(t)$ is odd and $\cos(\lambda t)$ is even, the product $f(t)\cos(\lambda t)$ is odd. Hence:
    $$A(\lambda) = \int_{-1}^1 t \cos(\lambda t) \, dt = 0$$
  - Since $f(t)$ is odd and $\sin(\lambda t)$ is odd, the product $f(t)\sin(\lambda t)$ is even. Hence:
    $$B(\lambda) = \int_{-1}^1 t \sin(\lambda t) \, dt = 2 \int_0^1 t \sin(\lambda t) \, dt$$

  Integrating by parts with $u = t \implies du = dt$, and $dv = \sin(\lambda t)dt \implies v = -\frac{\cos(\lambda t)}{\lambda}$:
  $$B(\lambda) = 2 \left[ \left( -\frac{t \cos(\lambda t)}{\lambda} \right)_0^1 - \int_0^1 \left(-\frac{\cos(\lambda t)}{\lambda}\right) dt \right]$$
  $$B(\lambda) = 2 \left[ -\frac{\cos\lambda}{\lambda} + \left[ \frac{\sin(\lambda t)}{\lambda^2} \right]_0^1 \right] = 2 \left[ -\frac{\cos\lambda}{\lambda} + \frac{\sin\lambda}{\lambda^2} \right]$$
  $$B(\lambda) = 2 \left[ \frac{\sin\lambda - \lambda \cos\lambda}{\lambda^2} \right]$$

  Substituting $A(\lambda) = 0$ and $B(\lambda)$ into the Fourier integral:
  $$f(x) = \frac{2}{\pi} \int_0^\infty \left( \frac{\sin\lambda - \lambda \cos\lambda}{\lambda^2} \right) \sin(\lambda x) \, d\lambda$$

### 12. Solve:
$$y' - 2y - 4x = 0 \quad \text{with } y(0) = 1$$

**Solution:**
Rewriting the differential equation in standard first-order linear form $\frac{dy}{dx} + P(x)y = Q(x)$:
$$\frac{dy}{dx} - 2y = 4x$$
Here, $P(x) = -2$ and $Q(x) = 4x$.

1. **Integrating Factor (I.F.):**
   $$\text{I.F.} = e^{\int P(x) \, dx} = e^{\int -2 \, dx} = e^{-2x}$$

2. **General Solution:**
   Multiplying both sides by the integrating factor:
   $$y \cdot e^{-2x} = \int Q(x) \cdot e^{-2x} \, dx + C = \int 4x e^{-2x} \, dx + C$$

   Integrate $\int 4x e^{-2x} \, dx$ by parts ($u = 4x, dv = e^{-2x}dx$):
   $$\int 4x e^{-2x} \, dx = 4x \left( \frac{e^{-2x}}{-2} \right) - \int 4 \left( \frac{e^{-2x}}{-2} \right) dx = -2x e^{-2x} + 2 \int e^{-2x} \, dx$$
   $$\int 4x e^{-2x} \, dx = -2x e^{-2x} - e^{-2x}$$

   Therefore:
   $$y e^{-2x} = -2x e^{-2x} - e^{-2x} + C$$
   Dividing throughout by $e^{-2x}$:
   $$y(x) = -2x - 1 + C e^{2x}$$

3. **Applying Initial Condition $y(0) = 1$:**
   $$1 = -2(0) - 1 + C e^0 \implies 1 = -1 + C \implies C = 2$$

Thus, the particular solution is:
$$y(x) = 2e^{2x} - 2x - 1$$

### 13. Find the general solution of the differential equation:
$$\frac{d^2 y}{dx^2} - 13 \frac{dy}{dx} + 12y = e^{-2x}$$

**Solution:**
Writing the equation in operator form $(D^2 - 13D + 12)y = e^{-2x}$, where $D = \frac{d}{dx}$.

1. **Complementary Function ($y_c$):**
   The auxiliary equation is:
   $$m^2 - 13m + 12 = 0$$
   $$(m - 1)(m - 12) = 0 \implies m_1 = 1, \quad m_2 = 12$$
   Since the roots are real and distinct:
   $$y_c = c_1 e^x + c_2 e^{12x}$$

2. **Particular Integral ($y_p$):**
   $$y_p = \frac{1}{D^2 - 13D + 12} e^{-2x}$$
   Using the exponential rule $\frac{1}{f(D)} e^{ax} = \frac{e^{ax}}{f(a)}$, provided $f(a) \ne 0$. Here $a = -2$:
   $$f(-2) = (-2)^2 - 13(-2) + 12 = 4 + 26 + 12 = 42 \ne 0$$
   $$y_p = \frac{e^{-2x}}{42}$$

3. **General Solution:**
   $$y = y_c + y_p = c_1 e^x + c_2 e^{12x} + \frac{1}{42} e^{-2x}$$
   where $c_1, c_2$ are arbitrary constants.

### 14. Find the Fourier series for the function:
$$f(x) = x^2, \quad 0 \le x \le \pi$$

**Solution:**
For half-range Fourier series in $0 \le x \le \pi$ with $L = \pi$, we represent $f(x)$ as a half-range cosine series:
$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty a_n \cos(nx)$$

1. **Compute $a_0$:**
   $$a_0 = \frac{2}{\pi} \int_0^\pi x^2 \, dx = \frac{2}{\pi} \left[ \frac{x^3}{3} \right]_0^\pi = \frac{2}{\pi} \cdot \frac{\pi^3}{3} = \frac{2\pi^2}{3}$$
   $$\implies \frac{a_0}{2} = \frac{\pi^2}{3}$$

2. **Compute $a_n$:**
   $$a_n = \frac{2}{\pi} \int_0^\pi x^2 \cos(nx) \, dx$$
   Using integration by parts repeatedly:
   $$\int x^2 \cos(nx) \, dx = x^2 \left(\frac{\sin nx}{n}\right) - 2x \left(-\frac{\cos nx}{n^2}\right) + 2 \left(-\frac{\sin nx}{n^3}\right)$$
   Evaluating between $0$ and $\pi$, noting that $\sin(n\pi) = \sin(0) = 0$:
   $$a_n = \frac{2}{\pi} \left[ \frac{2x \cos(nx)}{n^2} \right]_0^\pi = \frac{2}{\pi} \left( \frac{2\pi \cos(n\pi)}{n^2} - 0 \right) = \frac{4(-1)^n}{n^2}$$

3. **Fourier Series:**
   $$x^2 = \frac{\pi^2}{3} + 4 \sum_{n=1}^\infty \frac{(-1)^n}{n^2} \cos(nx) \quad (0 \le x \le \pi)$$
   Expanded:
   $$x^2 = \frac{\pi^2}{3} - 4 \left( \cos x - \frac{\cos 2x}{4} + \frac{\cos 3x}{9} - \dots \right)$$

### 15. Obtain the half-range cosine series for $f(x) = \sin x$ in $0 \le x \le \pi$ and hence show that:
$$\sum_{n=1}^\infty \frac{1}{4n^2 - 1} = \frac{1}{2}$$

**Solution:**
The half-range cosine series for $f(x)$ in $[0, \pi]$ is:
$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty a_n \cos(nx)$$

1. **Compute $a_0$:**
   $$a_0 = \frac{2}{\pi} \int_0^\pi \sin x \, dx = \frac{2}{\pi} [-\cos x]_0^\pi = \frac{2}{\pi} [-\cos\pi + \cos 0] = \frac{2}{\pi}(1 + 1) = \frac{4}{\pi}$$
   $$\implies \frac{a_0}{2} = \frac{2}{\pi}$$

2. **Compute $a_n$:**
   $$a_n = \frac{2}{\pi} \int_0^\pi \sin x \cos(nx) \, dx = \frac{1}{\pi} \int_0^\pi 2\sin x \cos(nx) \, dx$$
   Using $2\sin A \cos B = \sin(A + B) + \sin(A - B) = \sin((n+1)x) - \sin((n-1)x)$:
   $$a_n = \frac{1}{\pi} \int_0^\pi [\sin((1+n)x) + \sin((1-n)x)] \, dx$$

   - For $n = 1$:
     $$a_1 = \frac{2}{\pi} \int_0^\pi \sin x \cos x \, dx = \frac{1}{\pi} \int_0^\pi \sin(2x) \, dx = \frac{1}{\pi} \left[ -\frac{\cos 2x}{2} \right]_0^\pi = 0$$

   - For $n > 1$:
     $$a_n = \frac{1}{\pi} \left[ -\frac{\cos((n+1)x)}{n+1} + \frac{\cos((n-1)x)}{n-1} \right]_0^\pi$$
     $$a_n = \frac{1}{\pi} \left[ \left(-\frac{(-1)^{n+1}}{n+1} + \frac{(-1)^{n-1}}{n-1}\right) - \left(-\frac{1}{n+1} + \frac{1}{n-1}\right) \right]$$
     Notice $(-1)^{n+1} = (-1)^{n-1}$:
     $$a_n = \frac{1}{\pi} \left( \frac{1 - (-1)^{n+1}}{n+1} - \frac{1 - (-1)^{n-1}}{n-1} \right) = \frac{1 - (-1)^{n+1}}{\pi} \left( \frac{1}{n+1} - \frac{1}{n-1} \right)$$
     $$a_n = \frac{1 - (-1)^{n+1}}{\pi} \left( \frac{-2}{n^2 - 1} \right)$$
     - When $n$ is odd ($n = 3, 5, 7, \dots$): $(-1)^{n+1} = 1 \implies a_n = 0$.
     - When $n$ is even ($n = 2m$ for $m = 1, 2, 3, \dots$): $(-1)^{n+1} = -1$:
       $$a_{2m} = \frac{2}{\pi} \left( \frac{-2}{(2m)^2 - 1} \right) = -\frac{4}{\pi(4m^2 - 1)}$$

   Substituting into the Fourier series:
   $$\sin x = \frac{2}{\pi} - \frac{4}{\pi} \sum_{m=1}^\infty \frac{\cos(2mx)}{4m^2 - 1}, \quad 0 \le x \le \pi$$

3. **Deduction:**
   Setting $x = 0$ in the series:
   $$\sin(0) = \frac{2}{\pi} - \frac{4}{\pi} \sum_{m=1}^\infty \frac{\cos(0)}{4m^2 - 1}$$
   $$0 = \frac{2}{\pi} - \frac{4}{\pi} \sum_{m=1}^\infty \frac{1}{4m^2 - 1}$$
   $$\frac{4}{\pi} \sum_{m=1}^\infty \frac{1}{4m^2 - 1} = \frac{2}{\pi}$$
   $$\sum_{m=1}^\infty \frac{1}{4m^2 - 1} = \frac{2}{\pi} \times \frac{\pi}{4} = \frac{1}{2}$$

   Hence proved:
   $$\sum_{n=1}^\infty \frac{1}{4n^2 - 1} = \frac{1}{2}$$

### 16. Verify Cauchy-Riemann equation for the function:
$$f(z) = e^x(\cos y + i \sin y)$$

**Solution:**
Given:
$$f(z) = e^x \cos y + i e^x \sin y = u(x, y) + i v(x, y)$$
where:
$$u(x, y) = e^x \cos y, \qquad v(x, y) = e^x \sin y$$

Computing the partial derivatives:
1. With respect to $x$:
   $$\frac{\partial u}{\partial x} = \frac{\partial}{\partial x}(e^x \cos y) = e^x \cos y$$
   $$\frac{\partial v}{\partial x} = \frac{\partial}{\partial x}(e^x \sin y) = e^x \sin y$$

2. With respect to $y$:
   $$\frac{\partial u}{\partial y} = \frac{\partial}{\partial y}(e^x \cos y) = -e^x \sin y$$
   $$\frac{\partial v}{\partial y} = \frac{\partial}{\partial y}(e^x \sin y) = e^x \cos y$$

Checking the Cauchy-Riemann equations:
- **First C-R Equation:**
  $$\frac{\partial u}{\partial x} = e^x \cos y = \frac{\partial v}{\partial y} \quad \checkmark$$
- **Second C-R Equation:**
  $$\frac{\partial u}{\partial y} = -e^x \sin y = -\left(\frac{\partial v}{\partial x}\right) \quad \implies \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x} \quad \checkmark$$

Since the partial derivatives are continuous everywhere in the complex plane and satisfy:
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y} \quad \text{and} \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$
the Cauchy-Riemann equations are completely verified, and $f(z) = e^z$ is an entire analytic function.

### 17. Find the Laurent's series for:
$$f(z) = \frac{1}{(1 - z)(z + 2)} \quad \text{valid for the domain } 1 < |z| < 2$$

**Solution:**
1. **Partial Fraction Decomposition:**
   $$f(z) = \frac{1}{(1 - z)(z + 2)} = \frac{A}{1 - z} + \frac{B}{z + 2}$$
   $$1 = A(z + 2) + B(1 - z)$$
   - Putting $z = 1$: $1 = 3A \implies A = \frac{1}{3}$
   - Putting $z = -2$: $1 = 3B \implies B = \frac{1}{3}$

   $$f(z) = \frac{1}{3} \cdot \frac{1}{1 - z} + \frac{1}{3} \cdot \frac{1}{z + 2}$$

2. **Expansion in the Annulus $1 < |z| < 2$:**
   - For $|z| > 1$, we have $\left|\frac{1}{z}\right| < 1$:
     $$\frac{1}{1 - z} = -\frac{1}{z(1 - 1/z)} = -\frac{1}{z} \left(1 - \frac{1}{z}\right)^{-1} = -\frac{1}{z} \sum_{n=0}^\infty \left(\frac{1}{z}\right)^n = -\sum_{n=0}^\infty \frac{1}{z^{n+1}} = -\sum_{n=1}^\infty \frac{1}{z^n}$$
   - For $|z| < 2$, we have $\left|\frac{z}{2}\right| < 1$:
     $$\frac{1}{z + 2} = \frac{1}{2\left(1 + \frac{z}{2}\right)} = \frac{1}{2} \left(1 + \frac{z}{2}\right)^{-1} = \frac{1}{2} \sum_{n=0}^\infty (-1)^n \left(\frac{z}{2}\right)^n = \sum_{n=0}^\infty \frac{(-1)^n z^n}{2^{n+1}}$$

3. **Combined Laurent Series:**
   $$f(z) = -\frac{1}{3} \sum_{n=1}^\infty \frac{1}{z^n} + \frac{1}{3} \sum_{n=0}^\infty \frac{(-1)^n}{2^{n+1}} z^n$$

### 18. Solve:
$$x \frac{dy}{dx} + 2y = x^2 \log x$$

**Solution:**
Dividing throughout by $x$ to express in standard linear form $\frac{dy}{dx} + P(x)y = Q(x)$:
$$\frac{dy}{dx} + \frac{2}{x}y = x \log x$$
Here, $P(x) = \frac{2}{x}$ and $Q(x) = x \log x$.

1. **Integrating Factor (I.F.):**
   $$\text{I.F.} = e^{\int \frac{2}{x} \, dx} = e^{2\ln x} = e^{\ln(x^2)} = x^2$$

2. **General Solution:**
   $$y \cdot x^2 = \int (x \log x) \cdot x^2 \, dx + C = \int x^3 \log x \, dx + C$$

   Integrate $\int x^3 \log x \, dx$ by parts ($u = \log x, dv = x^3 dx \implies du = \frac{1}{x}dx, v = \frac{x^4}{4}$):
   $$\int x^3 \log x \, dx = \frac{x^4}{4} \log x - \int \frac{x^4}{4} \cdot \frac{1}{x} \, dx = \frac{x^4}{4} \log x - \frac{1}{4} \int x^3 \, dx$$
   $$\int x^3 \log x \, dx = \frac{x^4}{4} \log x - \frac{x^4}{16}$$

   Substituting back:
   $$y x^2 = \frac{x^4}{4} \log x - \frac{x^4}{16} + C$$
   Dividing throughout by $x^2$:
   $$y(x) = \frac{x^2}{4} \log x - \frac{x^2}{16} + \frac{C}{x^2}$$

### 19. Find by double integration, the area which lies inside the cardioid $r = a(1 + \cos\theta)$ and outside the circle $r = a$.

**Solution:**
1. **Points of Intersection:**
   Equating the two curves:
   $$a(1 + \cos\theta) = a \implies 1 + \cos\theta = 1 \implies \cos\theta = 0$$
   $$\theta = -\frac{\pi}{2} \quad \text{to} \quad \theta = \frac{\pi}{2}$$

2. **Area Setup via Symmetry:**
   Due to symmetry across the initial line ($\theta = 0$), the total area is twice the area in the first quadrant:
   $$\text{Area} = 2 \int_0^{\pi/2} \int_{r=a}^{a(1+\cos\theta)} r \, dr \, d\theta$$

3. **Evaluating the Inner Integral:**
   $$\int_a^{a(1+\cos\theta)} r \, dr = \left[ \frac{r^2}{2} \right]_a^{a(1+\cos\theta)} = \frac{a^2}{2} \left[ (1 + \cos\theta)^2 - 1 \right]$$
   $$= \frac{a^2}{2} (1 + 2\cos\theta + \cos^2\theta - 1) = \frac{a^2}{2} (2\cos\theta + \cos^2\theta)$$

4. **Evaluating the Outer Integral:**
   $$\text{Area} = 2 \int_0^{\pi/2} \frac{a^2}{2} (2\cos\theta + \cos^2\theta) \, d\theta = a^2 \int_0^{\pi/2} (2\cos\theta + \cos^2\theta) \, d\theta$$
   - $\int_0^{\pi/2} 2\cos\theta \, d\theta = 2 [\sin\theta]_0^{\pi/2} = 2(1 - 0) = 2$
   - $\int_0^{\pi/2} \cos^2\theta \, d\theta = \int_0^{\pi/2} \frac{1 + \cos 2\theta}{2} \, d\theta = \left[ \frac{\theta}{2} + \frac{\sin 2\theta}{4} \right]_0^{\pi/2} = \frac{\pi}{4}$

   Adding the two parts:
   $$\text{Area} = a^2 \left( 2 + \frac{\pi}{4} \right) = a^2 \left( \frac{8 + \pi}{4} \right)$$

$$\therefore \text{Area} = \frac{a^2(8 + \pi)}{4} \text{ sq. units}$$

### 21. Solve:
$$\frac{dy}{dx} = \frac{x + 2y - 3}{2x + y - 3}$$

**Solution:**
This is a non-homogeneous differential equation reducible to homogeneous form.
Let $x = X + h$ and $y = Y + k$, where $h, k$ are constants chosen to eliminate the constants $-3$:
$$\frac{dY}{dX} = \frac{(X + h) + 2(Y + k) - 3}{2(X + h) + (Y + k) - 3} = \frac{X + 2Y + (h + 2k - 3)}{2X + Y + (2h + k - 3)}$$

Setting:
1. $h + 2k = 3$
2. $2h + k = 3$

Subtracting: $(2h + k) - (h + 2k) = h - k = 0 \implies h = k$.
Then $3h = 3 \implies h = 1, k = 1$.
Thus $X = x - 1$ and $Y = y - 1$.

The equation becomes homogeneous:
$$\frac{dY}{dX} = \frac{X + 2Y}{2X + Y}$$

Let $Y = vX \implies \frac{dY}{dX} = v + X\frac{dv}{dX}$:
$$v + X\frac{dv}{dX} = \frac{X + 2vX}{2X + vX} = \frac{1 + 2v}{2 + v}$$
$$X\frac{dv}{dX} = \frac{1 + 2v}{2 + v} - v = \frac{1 + 2v - 2v - v^2}{2 + v} = \frac{1 - v^2}{2 + v}$$

Separating the variables:
$$\frac{2 + v}{1 - v^2} \, dv = \frac{dX}{X}$$
Using partial fractions: $\frac{2 + v}{(1 - v)(1 + v)} = \frac{A}{1 - v} + \frac{B}{1 + v}$:
- $v = 1 \implies 3 = 2A \implies A = 3/2$
- $v = -1 \implies 1 = 2B \implies B = 1/2$

Integrating:
$$\frac{3}{2} \int \frac{dv}{1 - v} + \frac{1}{2} \int \frac{dv}{1 + v} = \int \frac{dX}{X}$$
$$-\frac{3}{2} \ln|1 - v| + \frac{1}{2} \ln|1 + v| = \ln|X| + \ln C$$
Multiplying by $2$:
$$\ln|1 + v| - 3\ln|1 - v| = 2\ln|X| + 2\ln C = \ln(C_1 X^2)$$
$$\ln\left| \frac{1 + v}{(1 - v)^3} \right| = \ln(C_1 X^2) \implies \frac{1 + v}{(1 - v)^3} = C_1 X^2$$

Substituting $v = \frac{Y}{X}$:
$$\frac{1 + \frac{Y}{X}}{\left(1 - \frac{Y}{X}\right)^3} = C_1 X^2 \implies \frac{\frac{X + Y}{X}}{\frac{(X - Y)^3}{X^3}} = C_1 X^2 \implies \frac{X^2 (X + Y)}{(X - Y)^3} = C_1 X^2$$
$$\frac{X + Y}{(X - Y)^3} = C_1 \implies X + Y = C_1 (X - Y)^3$$

Substituting $X = x - 1$ and $Y = y - 1$:
$$(x - 1) + (y - 1) = C_1 [(x - 1) - (y - 1)]^3$$
$$(x + y - 2) = C_1 (x - y)^3$$

$$\therefore x + y - 2 = C(x - y)^3$$

### 22. Find the general solution of the differential equation:
$$\frac{d^2 y}{dx^2} - 2 \frac{dy}{dx} + 4y = e^x \sin x$$

**Solution:**
In operator notation: $(D^2 - 2D + 4)y = e^x \sin x$.

1. **Complementary Function ($y_c$):**
   Auxiliary equation:
   $$m^2 - 2m + 4 = 0 \implies m = \frac{2 \pm \sqrt{4 - 16}}{2} = \frac{2 \pm 2i\sqrt{3}}{2} = 1 \pm i\sqrt{3}$$
   Roots are complex with $\alpha = 1, \beta = \sqrt{3}$:
   $$y_c = e^x \left( c_1 \cos(\sqrt{3}x) + c_2 \sin(\sqrt{3}x) \right)$$

2. **Particular Integral ($y_p$):**
   $$y_p = \frac{1}{D^2 - 2D + 4} (e^x \sin x)$$
   Using the exponential shift formula $\frac{1}{f(D)} [e^{ax} V(x)] = e^{ax} \frac{1}{f(D + a)} V(x)$ with $a = 1$:
   $$y_p = e^x \frac{1}{(D + 1)^2 - 2(D + 1) + 4} \sin x$$

   So:
   $$y_p = e^x \frac{1}{D^2 + 3} \sin x$$

   $$y_p = e^x \frac{\sin x}{-1 + 3} = \frac{1}{2} e^x \sin x$$

3. **General Solution:**

### 23. Obtain the Fourier series for:
$$f(x) = \begin{cases} x, & \text{for } -1 < x \le 0 \\ x + 2, & \text{for } 0 < x \le 1 \end{cases}$$

**Solution:**
The function is given on $(-1, 1)$, with semi-period $L = 1$.
The Fourier series is:
$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty \left[ a_n \cos(n\pi x) + b_n \sin(n\pi x) \right]$$

1. **Calculate $a_0$:**
   $$a_0 = \frac{1}{1} \int_{-1}^1 f(x) \, dx = \int_{-1}^0 x \, dx + \int_0^1 (x + 2) \, dx$$
   $$\int_{-1}^0 x \, dx = \left[ \frac{x^2}{2} \right]_{-1}^0 = 0 - \frac{1}{2} = -\frac{1}{2}$$
   $$\int_0^1 (x + 2) \, dx = \left[ \frac{x^2}{2} + 2x \right]_0^1 = \frac{1}{2} + 2 = \frac{5}{2}$$
   $$a_0 = -\frac{1}{2} + \frac{5}{2} = 2 \implies \frac{a_0}{2} = 1$$

2. **Calculate $a_n$:**
   $$a_n = \int_{-1}^0 x \cos(n\pi x) \, dx + \int_0^1 (x + 2)\cos(n\pi x) \, dx$$
   $$= \int_{-1}^1 x \cos(n\pi x) \, dx + 2 \int_0^1 \cos(n\pi x) \, dx$$
   - Since $x \cos(n\pi x)$ is odd on $[-1, 1]$, its integral is $0$.
   - For the second integral:
     $$2 \int_0^1 \cos(n\pi x) \, dx = 2 \left[ \frac{\sin(n\pi x)}{n\pi} \right]_0^1 = 0$$
   Therefore:
   $$a_n = 0 \quad \text{for all } n \ge 1$$

3. **Calculate $b_n$:**
   $$b_n = \int_{-1}^0 x \sin(n\pi x) \, dx + \int_0^1 (x + 2)\sin(n\pi x) \, dx$$
   $$= \int_{-1}^1 x \sin(n\pi x) \, dx + 2 \int_0^1 \sin(n\pi x) \, dx$$
   - Since $x \sin(n\pi x)$ is even on $[-1, 1]$:
     $$\int_{-1}^1 x \sin(n\pi x) \, dx = 2 \int_0^1 x \sin(n\pi x) \, dx = 2 \left[ -\frac{x \cos(n\pi x)}{n\pi} + \frac{\sin(n\pi x)}{(n\pi)^2} \right]_0^1 = -\frac{2(-1)^n}{n\pi}$$
   - For the second integral:
     $$2 \int_0^1 \sin(n\pi x) \, dx = 2 \left[ -\frac{\cos(n\pi x)}{n\pi} \right]_0^1 = -\frac{2}{n\pi} [(-1)^n - 1] = \frac{2(1 - (-1)^n)}{n\pi}$$

   Adding the two terms:
   $$b_n = -\frac{2(-1)^n}{n\pi} + \frac{2 - 2(-1)^n}{n\pi} = \frac{2 - 4(-1)^n}{n\pi} = \frac{2[1 - 2(-1)^n]}{n\pi}$$

4. **Resulting Fourier Series:**
   $$f(x) = 1 + \frac{2}{\pi} \sum_{n=1}^\infty \frac{1 - 2(-1)^n}{n} \sin(n\pi x)$$
   Expanded:
   $$f(x) = 1 + \frac{2}{\pi} \left( 3\sin(\pi x) - \frac{1}{2}\sin(2\pi x) + \frac{3}{3}\sin(3\pi x) - \dots \right)$$

### 24. Find an analytic function $f(z)$ whose real part is $u(x, y) = e^x \sin y$.

**Solution:**
Given real part: $u(x, y) = e^x \sin y$.
Let $f(z) = u(x, y) + i v(x, y)$ be the analytic function.

**Method 1: Milne-Thomson Method:**
Compute the partial derivatives of $u$:
$$\frac{\partial u}{\partial x} = e^x \sin y = \phi_1(x, y)$$
$$\frac{\partial u}{\partial y} = e^x \cos y = \phi_2(x, y)$$

By Milne-Thomson theorem, $f'(z) = \phi_1(z, 0) - i \phi_2(z, 0)$:
- $\phi_1(z, 0) = e^z \sin(0) = 0$
- $\phi_2(z, 0) = e^z \cos(0) = e^z$

Therefore:
$$f'(z) = 0 - i(e^z) = -i e^z$$

Integrating with respect to $z$:
$$f(z) = \int -i e^z \, dz = -i e^z + C$$
where $C$ is an arbitrary complex constant.

**Verification using Cauchy-Riemann Equations:**
$$-i e^z = -i e^{x + iy} = -i e^x (\cos y + i \sin y) = -i e^x \cos y + e^x \sin y = e^x \sin y - i e^x \cos y$$
Matching real parts:
$$u(x, y) = e^x \sin y \quad \checkmark$$
$$v(x, y) = -e^x \cos y + c$$

$$\therefore f(z) = -i e^z + C$$

### 25. Find the residue of:
$$f(z) = \frac{3z - 4}{z(z - 1)(z - 2)} \quad \text{at each of its poles.}$$

**Solution:**
The poles of $f(z)$ occur where the denominator vanishes:
$$z(z - 1)(z - 2) = 0 \implies z = 0, \quad z = 1, \quad z = 2$$
All three are **simple poles** (order 1).

Recall that for a simple pole at $z = z_0$:
$$\text{Res}(f, z_0) = \lim_{z \to z_0} (z - z_0) f(z)$$

1. **Residue at $z = 0$:**
   $$\text{Res}(f, 0) = \lim_{z \to 0} z \cdot \frac{3z - 4}{z(z - 1)(z - 2)} = \lim_{z \to 0} \frac{3z - 4}{(z - 1)(z - 2)} = \frac{3(0) - 4}{(0 - 1)(0 - 2)} = \frac{-4}{(-1)(-2)} = \frac{-4}{2} = -2$$

2. **Residue at $z = 1$:**
   $$\text{Res}(f, 1) = \lim_{z \to 1} (z - 1) \cdot \frac{3z - 4}{z(z - 1)(z - 2)} = \lim_{z \to 1} \frac{3z - 4}{z(z - 2)} = \frac{3(1) - 4}{1(1 - 2)} = \frac{-1}{1(-1)} = \frac{-1}{-1} = 1$$

3. **Residue at $z = 2$:**
   $$\text{Res}(f, 2) = \lim_{z \to 2} (z - 2) \cdot \frac{3z - 4}{z(z - 1)(z - 2)} = \lim_{z \to 2} \frac{3z - 4}{z(z - 1)} = \frac{3(2) - 4}{2(2 - 1)} = \frac{6 - 4}{2(1)} = \frac{2}{2} = 1$$

**Summary of Residues:**
- $\text{Res}(f, 0) = -2$
- $\text{Res}(f, 1) = 1$
- $\text{Res}(f, 2) = 1$

*(Verification check: $\sum \text{Res} = -2 + 1 + 1 = 0$, which matches $\lim_{z \to \infty} -z f(z) = 0$).*
