## Group A
**Answer ALL questions.** `[10 × 2 = 20]`

1. Evaluate the double integral:
   $$\int_1^3 \int_2^5 (2x^2 + 3y^2) \, dx \, dy$$

2. Solve:
   $$(x + y) \, dy + (y - x) \, dx = 0$$

3. Verify Cauchy-Riemann equations for the function:
   $$\cosh y \sin x + i \sinh y \cos x$$

4. A function $f(x)$ is defined as follows:
   $$f(x) = \begin{cases} 1, & 0 < x < 1 \\ 0, & x \ge 1 \end{cases}$$
   Find the Fourier cosine integral of $f(x)$.

5. Solve:
   $$p^2 - y^2 = 0 \quad \text{where } p = \frac{dy}{dx}$$

6. Express the function $f(z) = e^z$ in the form of $u(x, y) + i v(x, y)$.

7. Find the zeros and poles of the function:
   $$f(z) = \left(\frac{z + 1}{z^2 + 1}\right)^2$$

8. Define odd and even functions with examples.

9. Show that the function:
   $$f(z) = \frac{\sinh(z - z_0)}{z - z_0} \quad \text{has a removable singularity at } z = z_0.$$

10. Find the residue of:
    $$f(z) = \frac{3z - 4}{z(z - 1)(z - 2)}$$

## Group B
**Answer EIGHT questions.** `[8 × 5 = 40]`

11. Find by double integration, the area which lies inside the cardioid $r = a(1 + \cos\theta)$ and outside the circle $r = a$.

12. Solve:
    $$\frac{dy}{dx} = \frac{x^2 + xy + y^2}{x^2}$$

13. Find the orthogonal trajectories of the family of curves given by $y = k x^2; k \neq 0$.

14. Solve:
    $$\frac{d^2 y}{dx^2} + 2 \frac{dy}{dx} + y = 2x + x^2$$

15. Find the Fourier series for the function defined by:
    $$f(x) = \begin{cases} 1, & \text{for } 0 \le x \le \pi \\ -1, & \text{for } \pi \le x \le 2\pi \end{cases}$$

16. Expand $f(x) = x$ as a cosine series in the interval $0 \le x \le \pi$ and hence show that:
    $$1 + \frac{1}{3^2} + \frac{1}{5^2} + \dots = \frac{\pi^2}{8}$$

17. State and prove Cauchy-Riemann equations.

18. Expand $f(z) = \frac{1}{z}$ by Taylor's series about the point $z = 1$.

19. Show that $u = e^x (x \cos y - y \sin y)$ is a harmonic function and find the analytic function $f(z) = u + iv$.

20. Find the residue of:
    $$f(z) = \frac{3z - 4}{z(z - 1)(z - 2)} \quad \text{at each of its poles.}$$

## Group C
**Answer FOUR questions.** `[4 × 5 = 20]`

21. Find the volume bounded by the sphere $x^2 + y^2 + z^2 = a^2$ using triple integral.

22. Solve:
    $$\frac{d^2 y}{dx^2} + 4 \frac{dy}{dx} + 4y = e^{3x} + \cos 5x$$

23. Find the Fourier transform of the function:
    $$f(x) = \begin{cases} 1 - x^2, & \text{for } -1 < x < 1 \\ 0, & \text{otherwise} \end{cases}$$

24. Show that $u = e^x \cos y$ is harmonic and find an analytic function $f(z)$.

25. Obtain the Laurent series of the function $f(z) = \frac{\sin z}{z^6}$ and hence show that:
    $$\int_C \frac{\sin z}{z^6} \, dz = -\frac{1}{60} \pi i \quad \text{where } C \text{ is the circle } |z| = 2 \text{ taken in the counter-clockwise sense.}$$
