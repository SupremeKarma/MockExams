### Question 1
Evaluate the double integral:
$$\int_1^3 \int_2^5 (2x^2 + 3y^2) \, dx \, dy$$

#### 💡 Core Theory & Formulas Needed
1. **Iterated Double Integral:** Evaluated from innermost to outermost:
   $$\int_{y=c}^d \left[ \int_{x=a}^b f(x, y) \, dx \right] dy$$
2. **Partial Integration Rule:** When integrating with respect to $x$, treat $y$ as a constant.
3. **Power Rule:** $\int x^n \, dx = \frac{x^{n+1}}{n+1} + C$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Evaluate the inner integral with respect to $x$**
Treat $y$ as constant:
$$\int_{x=2}^5 (2x^2 + 3y^2) \, dx = \left[ \frac{2x^3}{3} + 3y^2 x \right]_{x=2}^{x=5}$$
Substitute $x = 5$ and $x = 2$:
$$= \left( \frac{2(125)}{3} + 3y^2(5) \right) - \left( \frac{2(8)}{3} + 3y^2(2) \right)$$
$$= \left( \frac{250}{3} + 15y^2 \right) - \left( \frac{16}{3} + 6y^2 \right) = \frac{234}{3} + 9y^2 = 78 + 9y^2$$

**Step 2: Evaluate the outer integral with respect to $y$**
$$\int_{y=1}^3 (78 + 9y^2) \, dy = \left[ 78y + \frac{9y^3}{3} \right]_1^3 = [ 78y + 3y^3 ]_1^3$$
Substitute $y = 3$ and $y = 1$:
$$= [78(3) + 3(27)] - [78(1) + 3(1)] = (234 + 81) - (78 + 3) = 315 - 81 = 234$$

**Final Answer:**
$$\int_1^3 \int_2^5 (2x^2 + 3y^2) \, dx \, dy = 234$$

### Question 2
Solve:
$$(x + y) \, dy + (y - x) \, dx = 0$$

#### 💡 Core Theory & Formulas Needed
1. **Homogeneous Differential Equation:** An equation of the form $\frac{dy}{dx} = f\left(\frac{y}{x}\right)$.
2. **Standard Substitution:** Substitute $y = vx \implies \frac{dy}{dx} = v + x \frac{dv}{dx}$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Rearrange into $\frac{dy}{dx}$ form**
$$(x + y) \, dy = (x - y) \, dx \implies \frac{dy}{dx} = \frac{x - y}{x + y} = \frac{1 - (y/x)}{1 + (y/x)}$$

**Step 2: Substitute $y = vx$**
$$v + x \frac{dv}{dx} = \frac{1 - v}{1 + v}$$
$$x \frac{dv}{dx} = \frac{1 - v}{1 + v} - v = \frac{1 - v - v - v^2}{1 + v} = \frac{1 - 2v - v^2}{1 + v}$$

**Step 3: Separate variables**
$$\frac{1 + v}{1 - 2v - v^2} \, dv = \frac{dx}{x} \implies \frac{v + 1}{v^2 + 2v - 1} \, dv = -\frac{dx}{x}$$

**Step 4: Integrate both sides**
Notice the numerator is proportional to the derivative of the denominator $\frac{d}{dv}(v^2 + 2v - 1) = 2v + 2 = 2(v + 1)$:
$$\frac{1}{2} \int \frac{2(v + 1)}{v^2 + 2v - 1} \, dv = -\int \frac{dx}{x}$$
$$\frac{1}{2} \ln|v^2 + 2v - 1| = -\ln|x| + \ln C \implies \ln|v^2 + 2v - 1| = \ln\left(\frac{C^2}{x^2}\right)$$
$$v^2 + 2v - 1 = \frac{k}{x^2}$$

**Step 5: Substitute back $v = y/x$**
$$\left(\frac{y^2}{x^2} + \frac{2y}{x} - 1\right) x^2 = k \implies y^2 + 2xy - x^2 = c$$

**Final Answer:**
$$y^2 + 2xy - x^2 = c$$

### Question 3
Verify Cauchy-Riemann equations for the function:
$$f(z) = \cosh y \sin x + i \sinh y \cos x$$

#### 💡 Core Theory & Formulas Needed
Cauchy-Riemann equations in Cartesian coordinates:
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$
Hyperbolic derivatives: $\frac{d}{dy}(\cosh y) = \sinh y$, $\frac{d}{dy}(\sinh y) = \cosh y$.

#### 📝 Step-by-Step Complete Solution

**Step 1: Identify real and imaginary components**
$$u(x, y) = \cosh y \sin x, \qquad v(x, y) = \sinh y \cos x$$

**Step 2: Compute first-order partial derivatives**
- $\frac{\partial u}{\partial x} = \cosh y \cos x$
- $\frac{\partial u}{\partial y} = \sinh y \sin x$
- $\frac{\partial v}{\partial x} = -\sinh y \sin x$
- $\frac{\partial v}{\partial y} = \cosh y \cos x$

**Step 3: Compare pairs**
1. $\frac{\partial u}{\partial x} = \cosh y \cos x = \frac{\partial v}{\partial y}$ (First C-R equation holds!)
2. $\frac{\partial u}{\partial y} = \sinh y \sin x = -(-\sinh y \sin x) = -\frac{\partial v}{\partial x}$ (Second C-R equation holds!)

**Conclusion:**
The Cauchy-Riemann equations are satisfied everywhere in $\mathbb{C}$.

$$f(x) = \frac{2}{\pi} \int_0^\infty \cos(\omega x) \left[ \int_0^\infty f(t) \cos(\omega t) \, dt \right] d\omega$$

$$f(x) = \frac{2}{\pi} \int_0^\infty \frac{\sin \omega \cos(\omega x)}{\omega} \, d\omega$$

### Question 9
Show that the function:
$$f(z) = \frac{\sinh(z - z_0)}{z - z_0} \quad \text{has a removable singularity at } z = z_0.$$

#### 📝 Step-by-Step Complete Solution
Let $w = z - z_0$. The Taylor series of $\sinh w$ about $w = 0$ is:
$$\sinh w = w + \frac{w^3}{3!} + \frac{w^5}{5!} + \dots$$
Dividing by $w = z - z_0$:
$$f(z) = \frac{\sinh(z - z_0)}{z - z_0} = 1 + \frac{(z - z_0)^2}{6} + \frac{(z - z_0)^4}{120} + \dots$$
- The Laurent series contains no negative powers of $(z - z_0)$ (the principal part is zero).
- Furthermore, $\lim_{z \to z_0} f(z) = \lim_{w \to 0} \frac{\sinh w}{w} = 1$ (finite limit exists).
Therefore, $z = z_0$ is a **removable singularity**.

### Question 10
Find the residue of:
$$f(z) = \frac{3z - 4}{z(z - 1)(z - 2)}$$

#### 📝 Step-by-Step Complete Solution
The poles are all simple poles at $z = 0$, $z = 1$, and $z = 2$.

1. **At $z = 0$:**
   $$\text{Res}(f, 0) = \lim_{z \to 0} z f(z) = \frac{3(0) - 4}{(0 - 1)(0 - 2)} = \frac{-4}{(-1)(-2)} = -2$$
2. **At $z = 1$:**
   $$\text{Res}(f, 1) = \lim_{z \to 1} (z - 1) f(z) = \frac{3(1) - 4}{1(1 - 2)} = \frac{-1}{-1} = 1$$

   $$\text{Res}(f, 2) = \lim_{z \to 2} (z - 2) f(z) = \frac{3(2) - 4}{2(2 - 1)} = \frac{2}{2} = 1$$

### Question 11
Find by double integration, the area which lies inside the cardioid $r = a(1 + \cos\theta)$ and outside the circle $r = a$.

#### 💡 Core Theory & Formulas Needed
Area in polar coordinates:
$$\text{Area} = \iint_R r \, dr \, d\theta = 2 \int_{\theta=0}^{\pi/2} \int_{r=a}^{a(1 + \cos\theta)} r \, dr \, d\theta$$

#### 📝 Step-by-Step Complete Solution
**Step 1: Determine points of intersection**
$$a(1 + \cos\theta) = a \implies \cos\theta = 0 \implies \theta = -\frac{\pi}{2} \text{ to } \frac{\pi}{2}$$
By symmetry about the initial line $\theta = 0$:
$$\text{Area} = 2 \int_0^{\pi/2} \left[ \int_a^{a(1 + \cos\theta)} r \, dr \right] d\theta$$

**Step 2: Evaluate the inner radial integral**
$$\int_a^{a(1 + \cos\theta)} r \, dr = \left[ \frac{r^2}{2} \right]_a^{a(1 + \cos\theta)} = \frac{a^2}{2} \left[ (1 + \cos\theta)^2 - 1 \right] = \frac{a^2}{2} (2\cos\theta + \cos^2\theta)$$

**Step 3: Integrate with respect to $\theta$**
$$\text{Area} = 2 \int_0^{\pi/2} \frac{a^2}{2} (2\cos\theta + \cos^2\theta) \, d\theta = a^2 \int_0^{\pi/2} \left( 2\cos\theta + \frac{1 + \cos 2\theta}{2} \right) d\theta$$
$$= a^2 \left[ 2\sin\theta + \frac{\theta}{2} + \frac{\sin 2\theta}{4} \right]_0^{\pi/2} = a^2 \left( 2(1) + \frac{\pi}{4} + 0 \right) = a^2 \left( 2 + \frac{\pi}{4} \right) = \frac{a^2(8 + \pi)}{4}$$

### Question 15
Find the Fourier series for the function defined by:
$$f(x) = \begin{cases} 1, & \text{for } 0 \le x \le \pi \\ -1, & \text{for } \pi \le x \le 2\pi \end{cases}$$

#### 📝 Step-by-Step Complete Solution
Period $2L = 2\pi \implies L = \pi$.
$$a_0 = \frac{1}{\pi} \left[ \int_0^\pi (1) \, dx + \int_\pi^{2\pi} (-1) \, dx \right] = \frac{1}{\pi} (\pi - \pi) = 0$$
$$a_n = \frac{1}{\pi} \left[ \int_0^\pi \cos nx \, dx - \int_\pi^{2\pi} \cos nx \, dx \right] = \frac{1}{\pi} [0 - 0] = 0$$
$$b_n = \frac{1}{\pi} \left[ \int_0^\pi \sin nx \, dx - \int_\pi^{2\pi} \sin nx \, dx \right] = \frac{1}{n\pi} \left[ (1 - \cos n\pi) - (\cos 2n\pi - \cos n\pi) \right]$$
Since $\cos 2n\pi = 1$:
$$b_n = \frac{1}{n\pi} [1 - (-1)^n - 1 + (-1)^n] \text{ -- wait: } \int_\pi^{2\pi} \sin nx \, dx = \left[ -\frac{\cos nx}{n} \right]_\pi^{2\pi} = -\frac{1 - (-1)^n}{n}$$
$$b_n = \frac{1}{\pi} \left( \frac{1 - (-1)^n}{n} - \left(-\frac{1 - (-1)^n}{n}\right) \right) = \frac{2(1 - (-1)^n)}{n\pi}$$
- When $n$ is even: $(-1)^n = 1 \implies b_n = 0$.
- When $n$ is odd: $(-1)^n = -1 \implies b_n = \frac{4}{n\pi}$.

**Final Fourier Series:**
$$f(x) = \frac{4}{\pi} \sum_{n=1,3,5\dots}^\infty \frac{\sin nx}{n} = \frac{4}{\pi} \left( \sin x + \frac{\sin 3x}{3} + \frac{\sin 5x}{5} + \dots \right)$$

### Question 16
Expand $f(x) = x$ as a cosine series in the interval $0 \le x \le \pi$ and hence show that:

### Question 17
State and prove Cauchy-Riemann equations.

#### 📝 Complete Statement & Proof
**Statement:** If $f(z) = u(x, y) + i v(x, y)$ is differentiable at a point $z = x + iy$, then the first-order partial derivatives of $u$ and $v$ exist and satisfy:
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y} \quad \text{and} \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

**Proof:**
By definition:
$$f'(z) = \lim_{\Delta z \to 0} \frac{f(z + \Delta z) - f(z)}{\Delta z}$$
where $\Delta z = \Delta x + i \Delta y$.

**Case 1: Let $\Delta z \to 0$ horizontally ($\Delta y = 0, \Delta z = \Delta x$):**
$$f'(z) = \lim_{\Delta x \to 0} \frac{u(x+\Delta x, y) - u(x,y)}{\Delta x} + i \lim_{\Delta x \to 0} \frac{v(x+\Delta x, y) - v(x,y)}{\Delta x} = \frac{\partial u}{\partial x} + i \frac{\partial v}{\partial x} \quad \text{--- (1)}$$

**Case 2: Let $\Delta z \to 0$ vertically ($\Delta x = 0, \Delta z = i\Delta y$):**
$$f'(z) = \lim_{\Delta y \to 0} \frac{u(x, y+\Delta y) - u(x,y)}{i\Delta y} + i \lim_{\Delta y \to 0} \frac{v(x, y+\Delta y) - v(x,y)}{i\Delta y}$$
Since $\frac{1}{i} = -i$:
$$f'(z) = -i \frac{\partial u}{\partial y} + \frac{\partial v}{\partial y} = \frac{\partial v}{\partial y} - i \frac{\partial u}{\partial y} \quad \text{--- (2)}$$

Equating real and imaginary parts of (1) and (2):
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y} \quad \text{and} \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x} \quad \text{(Q.E.D.)}$$

### Question 21
Find the volume bounded by the sphere $x^2 + y^2 + z^2 = a^2$ using triple integral.

#### 📝 Step-by-Step Complete Solution
Transform to spherical polar coordinates:
$$x = \rho \sin\phi \cos\theta, \quad y = \rho \sin\phi \sin\theta, \quad z = \rho \cos\phi$$
Volume element: $dV = \rho^2 \sin\phi \, d\rho \, d\phi \, d\theta$.
Limits: $\rho \in [0, a], \; \phi \in [0, \pi], \; \theta \in [0, 2\pi]$.

$$V = \int_0^{2\pi} d\theta \int_0^\pi \sin\phi \, d\phi \int_0^a \rho^2 \, d\rho$$
$$= [ \theta ]_0^{2\pi} \cdot [ -\cos\phi ]_0^\pi \cdot \left[ \frac{\rho^3}{3} \right]_0^a$$
$$= (2\pi) \cdot (1 - (-1)) \cdot \left(\frac{a^3}{3}\right) = (2\pi)(2)\left(\frac{a^3}{3}\right) = \frac{4}{3} \pi a^3$$

### Question 22
Solve:
$$\frac{d^2 y}{dx^2} + 4 \frac{dy}{dx} + 4y = e^{3x} + \cos 5x$$

#### 📝 Step-by-Step Complete Solution
$(D + 2)^2 y = e^{3x} + \cos 5x$.
Auxiliary equation: $(m + 2)^2 = 0 \implies m = -2, -2 \implies y_c = (c_1 + c_2 x) e^{-2x}$.

**Particular Integral $y_{p1}$ for $e^{3x}$:**
$$y_{p1} = \frac{1}{(3 + 2)^2} e^{3x} = \frac{e^{3x}}{25}$$

**Particular Integral $y_{p2}$ for $\cos 5x$:**
Replace $D^2 \to -25$:
$$y_{p2} = \frac{1}{D^2 + 4D + 4} \cos 5x = \frac{1}{-25 + 4D + 4} \cos 5x = \frac{1}{4D - 21} \cos 5x$$
$$= \frac{4D + 21}{16D^2 - 441} \cos 5x = \frac{-20\sin 5x + 21\cos 5x}{16(-25) - 441} = \frac{21\cos 5x - 20\sin 5x}{-841}$$

**Complete Solution:**
$$y = (c_1 + c_2 x) e^{-2x} + \frac{e^{3x}}{25} - \frac{21\cos 5x - 20\sin 5x}{841}$$

### Question 23
Find the Fourier transform of the function:
$$f(x) = \begin{cases} 1 - x^2, & \text{for } -1 < x < 1 \\ 0, & \text{otherwise} \end{cases}$$

#### 📝 Step-by-Step Complete Solution
$$F(s) = \frac{1}{\sqrt{2\pi}} \int_{-1}^1 (1 - x^2) e^{-isx} \, dx$$
Since $1 - x^2$ is even and $\sin(sx)$ is odd:
$$F(s) = \sqrt{\frac{2}{\pi}} \int_0^1 (1 - x^2) \cos(sx) \, dx$$
Integrating by parts:
$$= \sqrt{\frac{2}{\pi}} \left( \left[ (1 - x^2) \frac{\sin sx}{s} \right]_0^1 - \int_0^1 (-2x) \frac{\sin sx}{s} \, dx \right) = \frac{2}{s} \sqrt{\frac{2}{\pi}} \int_0^1 x \sin sx \, dx$$
$$= \frac{2}{s} \sqrt{\frac{2}{\pi}} \left[ -x \frac{\cos sx}{s} + \frac{\sin sx}{s^2} \right]_0^1 = 2 \sqrt{\frac{2}{\pi}} \left( \frac{\sin s - s \cos s}{s^3} \right)$$

### Question 24
Show that $u = e^x \cos y$ is harmonic and find an analytic function $f(z)$.

#### 📝 Step-by-Step Complete Solution
$$u_x = e^x \cos y \implies u_{xx} = e^x \cos y$$
$$u_y = -e^x \sin y \implies u_{yy} = -e^x \cos y$$
$$u_{xx} + u_{yy} = 0 \implies u \text{ is harmonic!}$$

By Milne-Thomson method:
$$\phi_1(z, 0) = u_x(z, 0) = e^z \cos 0 = e^z$$
$$\phi_2(z, 0) = u_y(z, 0) = -e^z \sin 0 = 0$$
$$f'(z) = \phi_1(z, 0) - i\phi_2(z, 0) = e^z \implies f(z) = e^z + C$$

### Question 25
Obtain the Laurent series of the function $f(z) = \frac{\sin z}{z^6}$ and hence show that:
$$\int_C \frac{\sin z}{z^6} \, dz = \frac{\pi i}{60} \quad \text{where } C \text{ is the circle } |z| = 2 \text{ in counter-clockwise sense.}$$

#### 📝 Step-by-Step Complete Solution
Maclaurin expansion of $\sin z$:
$$\sin z = z - \frac{z^3}{3!} + \frac{z^5}{5!} - \frac{z^7}{7!} + \dots = z - \frac{z^3}{6} + \frac{z^5}{120} - \frac{z^7}{5040} + \dots$$
Divide by $z^6$:
$$f(z) = \frac{1}{z^5} - \frac{1}{6z^3} + \frac{1}{120z} - \frac{z}{5040} + \dots$$
- The singularity inside $|z| = 2$ is $z = 0$ (a pole of order 5).
- The residue is the coefficient of $z^{-1}$, which is $b_1 = \frac{1}{120}$.
By Cauchy's Residue Theorem:
$$\oint_C \frac{\sin z}{z^6} \, dz = 2\pi i \cdot \text{Res}(f, 0) = 2\pi i \left(\frac{1}{120}\right) = \frac{\pi i}{60}$$
