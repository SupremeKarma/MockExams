## Group A
**Answer ALL questions.** `[10 × 2 = 20]`

1. Evaluate:
   $$\int_0^a \int_0^a \int_0^a (x + y + z) \, dx \, dy \, dz$$

2. Evaluate the integral by changing the order of integration:
   $$\int_0^\infty \int_x^\infty \frac{e^{-y}}{y} \, dy \, dx$$

3. Determine the order and degree of the differential equation:
   $$\sqrt{\frac{d^3 y}{dx^3}} = \frac{dy}{dx}$$

4. Solve:
   $$(x + 1) \, dy = (y - 1) \, dx$$

5. Solve:
   $$\frac{d^2 y}{dx^2} - 4 \frac{dy}{dx} + 13 y = 0$$

6. Determine the function $f(x) = \log\left|\frac{1 - x}{1 + x}\right|$ is even or odd.

7. Express the function $f(z) = \sin z$ in the form of $u(x, y) + i v(x, y)$.

8. If $f(z)$ is differentiable at $z_0$, then show that $f(z)$ is continuous at $z = z_0$.

9. Find the zeros of the function:
   $$f(z) = \left(\frac{z + 2}{z^2 + 1}\right)^3$$

10. Show that the function:
    $$f(z) = \frac{z^2 - 2z + 5}{z - 2} \quad \text{has a simple pole at } z = 2.$$

## Group B
**Answer EIGHT questions.** `[8 × 5 = 40]`

11. Evaluate:
    $$\iint_R xy \, dx \, dy \quad \text{where } R \text{ is the positive quadrant of the circle } x^2 + y^2 = a^2.$$

12. Solve:
    $$\frac{dy}{dx} + \frac{y}{x^2} = \frac{1}{x^2}$$

13. Find the general solution of the differential equation:
    $$\frac{d^2 y}{dx^2} - \frac{dy}{dx} - 2y = 6e^x$$

14. Find the Fourier series for the function $f(x) = 2x, 0 \le x \le \pi$ where $f(x) = f(x + 2\pi)$.

15. Expand the following function in Fourier cosine series:
    $$f(x) = \begin{cases} 1, & 0 < x < \frac{\pi}{2} \\ 0, & \frac{\pi}{2} < x < \pi \end{cases}$$

16. Verify Cauchy-Riemann equation for the function:
    $$f(z) = \frac{x - iy}{x^2 + y^2}$$

17. Expand $f(z) = \frac{1}{z}$ by Taylor's series about the point $z = 1$.

18. Solve the equation:
    $$x \frac{dy}{dx} = y + x^2 \log x$$

19. State and prove the Cauchy Riemann equations.

20. A function $f(x)$ is defined by:
    $$f(x) = \begin{cases} 1, & \text{for } -1 \le x \le 1 \\ 0, & \text{otherwise} \end{cases}$$
    Find the Fourier integral representation of $f(x)$.
